# MarkCaptain 0.7.0

新增本地优先的云存储体系，支持私有自建同步服务、Git、WebDAV，以及通过统一协议接入第三方云盘的存储插件。编辑器始终先写入本地工作副本，网络或远端故障不会让本地保存失败。

## 云存储与同步

- 新增云存储设置页，可配置自建 MarkCaptain Sync、Git、WebDAV 和已安装的存储插件。
- 本地保存状态与云端同步状态完全分离，状态栏会显示等待同步、同步中、已同步、离线、冲突或错误。
- 同步引擎使用本地内容哈希、远端版本、稳定资源 ID 和远端内容哈希建立基线，不采用静默的最后写入者覆盖。
- 每个成功同步的路径都会原子更新清单，并通过持久化 journal 在崩溃后恢复，单个文件冲突不会破坏已经完成的其他同步结果。
- 远端不支持可靠条件写入时，MarkCaptain 会拒绝自动修改远端；安全的只读下载仍可继续。

## 自建同步服务

- 新增独立私有 `markcaptain-sync-server` 服务，使用 Axum、SQLite WAL 和文件系统内容 Blob，可通过 Docker Compose 部署。
- 服务端提供稳定文件 ID、不可变版本历史、增量变更游标、软删除墓碑和内容 SHA-256。
- 所有写入、移动与删除都要求条件版本；版本令牌绑定稳定资源 ID，可防止文件删除后同路径重建造成 ABA 覆盖。
- 失败或过期的条件写入不会遗留孤立 Blob，默认只监听 `127.0.0.1`，生产部署建议由反向代理提供 HTTPS。
- 密码和令牌只存入操作系统凭据库，不进入普通设置、SQLite、URL、命令参数或日志。

## Git 与 Agent 冲突审阅

- Git 存储支持仓库校验、fetch、仅快进 pull、非 force push，以及显式准备无自动提交的合并。
- Git 同步只传输已经提交的更改；分叉或冲突不会触发 reset、force push 或自动提交。
- 冲突既可以直接在工作区手动解决，也可以在写作 Agent 面板逐个审阅。
- Agent 只接收用户选择的单个冲突块及受限 BASE/LOCAL/REMOTE 内容，生成的修改仍需通过现有审阅界面明确应用，不会自动提交或推送。

## WebDAV 与存储插件

- WebDAV 支持 OPTIONS、PROPFIND、GET、PUT、MKCOL、MOVE、DELETE 和增量同步令牌。
- 仅使用强 ETag 执行条件修改；弱或缺失的 ETag 不会被当成安全版本。
- XML 响应采用流式限长读取，拒绝 DTD，并正确处理实体转义、CDATA 和逐段 URL 编码。
- 第三方网盘统一使用 Storage Plugin Protocol v1，不在主程序中增加特定厂商 API。
- 插件通过无 shell 的 JSON-RPC stdio 通信，校验 manifest/目录 ID，清理继承环境，限制请求、响应和运行时间。
- 文件内容通过 MarkCaptain 创建的临时文件传递，拒绝插件指定任意读取路径、符号链接和 Windows reparse point，单文件上限 64 MiB 或插件声明的更小值。
- 插件是用户明确安装的受信任原生程序；协议隔离并不等同于操作系统沙箱。

- TypeScript、ESLint、前端生产构建、Rust 格式检查、完整 Cargo 测试和差异检查通过。
