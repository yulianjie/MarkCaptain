# MarkCaptain 0.5.1

修复已有文件保存后仍显示「未保存」的问题，并保留保存前的光标位置和撤销记录。

## 保存修复

- 对于原本没有末尾换行的文件，正确区分编辑器自动补回的换行与真实内容修改，避免 Ctrl+S 或菜单保存成功后立即恢复「未保存」状态。
- 保存时仅存在末尾换行格式差异，不再重新解析整个文档，保留光标和撤销历史。
- 文件监听收到与已保存内容等价的磁盘版本时，保持正确保存状态；用户实际新增的空行仍保留为未保存修改。

## 验证

- 保存回归覆盖连续修改已有文件、有/无末尾换行、保存后移动光标、撤销、另存为和源码编辑。
- 独立 Windows WebView2 构建已验证 16 个已有文件真实写入磁盘，Ctrl+S 和原生菜单保存通过，通信回退压力测试后仍可保存。
- 233 项前端单元测试、3 项保存浏览器回归测试、生产构建、ESLint 和 Rust 检查通过。各平台安装包未逐一实机安装验收。

## 已知限制

长时间运行后多份文件完全无法写入磁盘的间歇性问题尚未稳定复现，本版不将其标记为已解决。

## 下载

- Windows x64：`x64-setup.exe` 或 `x64_en-US.msi`。
- Linux x64：AppImage、DEB、RPM。
- macOS：根据 Apple Silicon / Intel 选择对应的 `.app.tar.gz`；DMG 若成功生成会一并提供。
