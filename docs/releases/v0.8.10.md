# MarkCaptain 0.8.10

本版改进启动体验：默认直接启动显示主页，通过文件启动时选中传入的文件，不再额外创建 `Untitled-1` 空白文档。

## 启动与主页

- 空窗口默认显示并选中“开始”页签；只有主动新建文档时才创建 Untitled 文档。
- 通过文件关联或外部请求打开文件时，直接选中对应文档，不额外创建空白文档；文件打开失败时保留主页。
- 保留已有的“恢复最近文件”及启动文件夹设置，以及未保存草稿恢复流程；外部打开的文件仍在会话恢复后获得选中状态。
- 恢复旧分栏布局但没有恢复文档时，主页保持选中，避免窗格恢复抢走主页状态。
- 中、英、日设置文案同步更新，默认启动选项由“空白文档”改为“显示主页”。

## 验证

- 前端类型检查、ESLint、生产构建及 612 项单元测试通过。
- 180 项浏览器回归测试通过，覆盖主页启动、主动新建、延迟文件打开、会话恢复后的外部文件打开、打开失败、旧分栏布局，以及原有编辑、保存、历史恢复、Agent、笔记本和导出流程。
- 本次交互验证在浏览器渲染层完成，外部文件队列与磁盘读取使用测试替身；各平台安装及真实文件关联启动仍需在对应设备验收。

## 下载与更新

- Windows x64：NSIS `.exe` 或 MSI 安装包。
- Linux x64：AppImage、DEB、RPM。
- macOS：Apple Silicon／Intel 对应的 `.app.tar.gz`，以及成功生成的 DMG。
- 四平台更新包沿用既有 Tauri 更新签名，全部平台构建成功后发布 `latest.json`；`.sig` 和清单无需手动安装。
