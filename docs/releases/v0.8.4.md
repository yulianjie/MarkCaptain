# MarkCaptain 0.8.4

本版加入自动检查更新与应用内安装，补齐签名发布和更新清单流程。

## 自动检查与安装

- 默认在启动十秒后检查更新，运行期间每四小时检查一次；可在「偏好设置 → 通用 → 自动检查更新」关闭。帮助菜单仍可随时手动检查。
- 后台检查仅在发现新版本时显示提示；手动检查会显示检查结果，网络失败时可以重试。
- 更新窗口显示版本、发布说明和下载进度，由用户决定何时下载并安装。下载完成与安装完成分别处理，仅在安装成功后提供重启操作。
- 安装前保存全部文档、刷新 Agent 数据并保存编辑会话；保存取消或失败时暂停安装。其他编辑窗口未关闭时阻止安装与重启，避免进程退出导致内容丢失。
- 更新界面和偏好设置支持中文、英文、日文。

## 签名与发布

- 更新包使用 Tauri Minisign/Ed25519 签名，客户端验证下载内容，拒绝被篡改的文件。私钥通过 GitHub Actions Secret 提供，不随软件或源码发布。
- Windows x64、Linux x64、macOS Apple Silicon／Intel 分别生成签名更新包。全部平台构建成功后生成 `latest.json`，校验版本、下载来源及平台完整性。
- macOS 更新使用 Tauri 生成的原始签名归档，避免重新打包破坏签名。更新签名与操作系统的代码签名／公证是不同机制。

## 验证与使用边界

- 411 项前端单元测试、184 项 Rust 测试和 9 项针对更新设置、语言与编辑器的浏览器测试通过；类型检查、ESLint、生产构建和 Rust 编译检查通过。
- Windows WebView2 原生验证通过：真实插件检查、签名下载、篡改拒绝、中文窗口，以及多编辑窗口安装保护。更新测试使用隔离的本机服务与签名测试文件，没有执行测试文件作为安装程序。
- v0.8.3 及更早版本未启用更新功能，需要手动下载安装 v0.8.4 一次，之后可以接收后续签名版本更新。
- macOS／Linux 的真实安装启动及从旧版本运行系统安装程序升级，仍需对应系统实机验证。各平台安装包和更新清单以本次发布工作流与资产核验结果为准。

## 下载

- Windows x64：NSIS `.exe` 或 MSI；`MarkCaptain_v0.8.4_windows-x86_64.exe` 同时用于自动更新。
- Linux x64：AppImage、DEB、RPM。
- macOS：Apple Silicon／Intel 对应的 `.app.tar.gz`，以及成功生成的 DMG。
- `.sig` 和 `latest.json` 是自动更新校验与元数据文件，无需手动安装。
