# MarkCaptain 0.6.1

修复多屏使用时设置窗口留在已断开屏幕、再次打开仍找不到的问题，并完善编辑器窗口的位置恢复。

## 多屏窗口恢复

- 系统报告显示器断开、分辨率或缩放变化后，自动检查窗口是否仍可操作，将离屏窗口移回可用屏幕。
- 从编辑器再次打开设置时，复用的设置窗口会回到该编辑器所在屏幕；最小化的设置窗口会恢复显示。
- 启动、恢复焦点和再次启动程序时校验窗口位置，避免恢复到只有一角可见、标题栏无法操作的旧位置。
- 按目标屏幕的可用工作区调整位置和尺寸，考虑不同缩放比例、负坐标及任务栏占用；超大窗口必要时缩小到屏幕内。
- 自动恢复不抢焦点、不主动展开最小化窗口，正常放在副屏或跨屏的窗口保留原位。

如果关闭显示器后系统仍将它识别为已连接，可在正在使用的编辑器中再次打开设置，将设置带回当前屏幕。

## 验证

- 258 项前端单元测试、109 项 Rust 测试、前端生产构建、ESLint 和 Rust 格式检查通过。
- Windows 两块真实屏幕上的独立原生窗口测试通过，覆盖离屏恢复、指定屏幕放置、旧坐标、最大化与最小化、超大窗口、自动恢复和焦点保持。
- 三屏减少为两屏及混合缩放的几何场景由单元测试覆盖；未实际拔插显示器，未逐一安装验收各平台安装包。
