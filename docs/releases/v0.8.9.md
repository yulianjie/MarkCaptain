# MarkCaptain 0.8.9

本版修复点击主页后，欢迎内容显示在当前文档页签下，而标题、大纲和字数仍属于旧文档的问题。

## 独立开始页签

- 点击主页会打开并选中唯一的“开始”页签，重复点击不会创建副本；原有文档继续保留在各自页签中。
- 开始页签支持点击切换、方向键导航、中键关闭、关闭按钮、右键菜单及 Ctrl/Cmd+W。关闭开始页签后返回之前的文档。
- 主页选中时清空当前文档上下文，不再显示旧文档大纲或字数，禁用文档导出；查找快捷键不会切回隐藏文档。
- 返回文档时保留未保存内容、光标与撤销历史，兼容所见即所得、源码模式和分屏编辑。
- 从主页新建、打开最近文档或激活文件树/搜索结果时切换到对应文档；取消打开或打开失败时保留主页。
- 主页不作为文档或草稿保存。停留在主页时仍保存原有文档和窗格的会话位置，避免重启后恢复成空白编辑窗格。

## 验证

- 前端类型检查、ESLint、生产构建及 610 项单元测试通过。
- 浏览器回归覆盖开始页签切换与关闭、未保存内容和撤销、源码模式、分屏会话、最近文件、取消/失败打开、键盘操作，以及文档关闭、页签溢出和紧凑布局。
- 本次交互验证在浏览器渲染层完成；各平台安装和原生桌面操作仍需在对应设备验收。

## 下载与更新

- Windows x64：NSIS `.exe` 或 MSI 安装包。
- Linux x64：AppImage、DEB、RPM。
- macOS：Apple Silicon／Intel 对应的 `.app.tar.gz`，以及成功生成的 DMG。
- 四平台更新包沿用既有 Tauri 更新签名，全部平台构建成功后发布 `latest.json`；`.sig` 和清单无需手动安装。
