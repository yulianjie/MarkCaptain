# MarkCaptain 0.8.6

本版修复 Markdown 文档链接跳转：相对链接在 MarkCaptain 编辑器内打开对应文档，不再被 WebView 拼接为 `tauri.localhost` 网页地址。

## 文档链接

- 按住 Ctrl（macOS 为 Cmd）点击链接，或使用链接浮层的跳转按钮，在编辑器标签页中打开对应的 `.md` 文档；已经打开的文档复用现有标签页。
- 相对路径以源文档所在目录为基准，支持 `../`、中文与空格、URL 编码、引用式链接和标题锚点；单独打开文件时也能跳转，无需先打开项目。
- 所见即所得与源码模式使用相同的本地文档解析逻辑；项目内链接保留索引导航和分栏归属。
- 普通单击继续用于编辑，网页链接仍使用系统浏览器。缺失文件显示错误并保留源文档。
- 修复 Ctrl/Cmd+点击跳转后源链接浮层残留、遮挡后续链接的问题。

## 验证

- 600 项前端单元测试全部通过，其中相关 39 项覆盖文档链接和路径解析；9 项浏览器回归通过，覆盖单文件、链接浮层、源码模式、外部网页及分栏。
- Windows 原生 WebView2 完成 9 项检查，使用真实 Rust 文件读取和项目索引；验证中文路径、标题定位、引用式链接、缺失文件和标签页复用，源文件内容未改变。
- 类型检查、ESLint、生产构建及 Windows 原生测试构建通过。macOS/Linux 的安装和实际编辑仍需在对应设备验收。

## 下载与更新

- Windows x64：NSIS `.exe` 或 MSI 安装包。
- Linux x64：AppImage、DEB、RPM。
- macOS：Apple Silicon／Intel 对应的 `.app.tar.gz`，以及成功生成的 DMG。
- 四平台更新包沿用既有 Tauri 更新签名，全部平台构建成功后发布 `latest.json`；`.sig` 和清单无需手动安装。
