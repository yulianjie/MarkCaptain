# MarkCaptain 0.8.8

本版统一编辑器、写作 Agent、设置、导出与笔记界面，采用暖白、鼠尾草绿和石墨深色主题，改善窄窗口和键盘操作，并修复多页签关闭按钮被裁切、深色设置页原生标题栏未同步的问题。

## 写作工作台

- 统一工作区导航、标签页、文档路径、格式工具、画布、大纲和状态栏；开始页接入真实最近文件、新建和打开操作。
- 移除侧栏重复的“打开的文件”区域，文档继续通过顶部页签、快捷键和菜单管理。
- 阅读进度固定在大纲底部，目录独立滚动；短目录、长目录和窄窗口抽屉均保持可达。
- 多文档打开时保留可见页签的关闭按钮；溢出提供左右滚动入口，当前页签在新增、切换、排序或缩放后自动进入视野。
- 开始页切换保留编辑器实例与未保存内容；键盘激活当前文档和重复查找请求能返回正确的编辑位置。
- 窄窗口面板支持焦点循环、关闭恢复和分层 Escape 行为；调整侧栏宽度时不会出现被响应式上限吞掉的无响应区间。

## Agent、设置与导出

- Agent 上下文和工具/权限分层展示，精简输入区与嵌入标题栏；修改建议、差异、来源、历史、技能和设置采用一致样式。
- 保留逐项/批量应用、拒绝、撤销、过期与冲突阻断、历史锁定及外部访问授权；收起工具区不会撤销已有授权。
- 设置页增加分组与真实主题选择卡片，保留全部原有选项；修正窄窗口快捷键表格溢出和宽窗口内容过度居中的问题。
- 原生标题栏同步浅色、深色、自定义主题亮度与系统跟随，覆盖首次打开、重开设置和跨窗口切换。
- 单文档、批量和成书导出使用分组设置、真实预览和可达的底部操作区；未保存文档正确标记为缓冲区。
- 双链、标签、属性、搜索、任务、历史恢复、云存储及常用弹窗统一视觉层级，保留原工作流和功能入口。

## 验证

- 前端类型检查、ESLint、生产构建及 606 项单元测试通过。
- 浏览器回归覆盖编辑、保存与撤销、文档链接、Agent 审阅与权限、导出快照/取消/冲突、笔记、主题和布局；包含 4/8/12 个长文件名、800/1024/1440px、浅深主题的页签组合检查。
- Windows 原生 WebView2 完成真实文件打开、编辑保存、源码切换、隔离 HTML 预览和独立设置窗口检查；通过视口模拟验证四档桌面尺寸。
- 实际 Windows 窗口确认深色标题栏、跨窗口主题同步、重新打开设置及系统跟随。原生窗口命令单元测试通过。
- 模型、MCP 和云服务回归使用传输边界 fixture；macOS/Linux 的安装与编辑仍需在对应设备验收。

## 下载与更新

- Windows x64：NSIS `.exe` 或 MSI 安装包。
- Linux x64：AppImage、DEB、RPM。
- macOS：Apple Silicon／Intel 对应的 `.app.tar.gz`，以及成功生成的 DMG。
- 四平台更新包沿用既有 Tauri 更新签名，全部平台构建成功后发布 `latest.json`；`.sig` 和清单无需手动安装。
