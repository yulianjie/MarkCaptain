# MarkCaptain 0.3.5

修复紧凑布局下编辑器提示区域被裁切的问题，并让 `@` 插入菜单跟随应用语言切换。

## 修复与改进

- **完整显示段落操作入口**：正文两侧留白调整为 40px，避免左侧段落图标被滚动区域裁切；提高空白插入提示的文字对比度。
- **插入菜单多语言支持**：空白提示、菜单分类、标题、说明及无结果文案支持简体中文、英文和日文，切换语言即时生效。
- **本地化搜索**：可使用当前语言标题搜索插入项，同时保留英文名称与命令名称搜索；语言切换保留正文和正在输入的查询。
- **更清晰的菜单布局**：说明文字可换行，快捷键完整显示，窄窗口下可滚动访问全部插入项。
- **无结果时保护输入**：搜索无匹配项时按回车，不会误插入此前选中的内容。

## 下载

- Windows x64：`x64-setup.exe` 或 `x64_en-US.msi`。
- Linux x64：AppImage、DEB、RPM。
- macOS：根据 Apple Silicon / Intel 选择对应的 `.app.tar.gz`；DMG 若成功生成会一并提供。

## 验证

前端构建、ESLint、224 项单元测试及 14 项浏览器回归测试通过。浏览器检查覆盖不同窗口宽度、字体大小、侧栏显隐、多语言搜索及深色主题。各平台安装器尚未逐一实机验收。
