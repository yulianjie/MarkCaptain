# MarkCaptain 0.5.2

写作助手新增图片输入和选区自动附加。可以直接粘贴截图提问，也可以选中文章中的一段文字后进入助手，围绕这段内容继续写作。

## 图片输入

- 在消息输入框粘贴图片，或点击「添加图片」选择 PNG、JPEG、WebP 文件。
- 发送前显示缩略图，支持点击放大、逐张移除、图片与文字一起发送，以及只发送图片。
- 图片随当前文档的对话保留，后续追问和失败重试能够继续使用原来的图片。
- 每条消息最多 4 张图片，单张最多 5 MiB；每段对话最多 12 张、总计 20 MiB。图片与文档、聊天文字分别计量，普通截图不会触发原先的文本大小限制。
- 格式不支持、图片损坏、超出限制或服务拒绝图片请求时，显示具体提示。普通文字粘贴保持原有行为。

## 自动附加选中文字

- 选中文字后打开助手（`Ctrl/Cmd+Shift+A`）或点击消息输入框，会自动附加选区。
- 支持所见即所得和源码模式，可展开预览核对文字，也可手动重新附加或切回整篇文档。
- 关闭文档附加后不会自动重新开启；新建对话会保留此开关设置。
- 草稿图片、选区和附加设置按文档分别保存。读取图片时切换文档或清空对话，不会把附件混入其他对话。
- 修改建议继续使用不可变文档快照和审阅流程，文档变化后旧建议不能覆盖后续编辑。

## 模型与数据

图片输入使用 Chat Completions 兼容接口。所配置模型需要同时支持视觉输入、流式输出和工具调用；连接测试目前只验证文本请求。图片只在窗口内存保存，发送后交给配置的模型服务，不上传至其他图床。

## 验证

- 238 项前端单元测试、93 项 Rust 测试、11 项 Agent 浏览器测试、前端生产构建和 ESLint 通过。
- 独立 Windows WebView2 构建已验证系统剪贴板真实 `Ctrl+V`、选区自动附加、图片文件选择、仅图片发送、后续追问，以及 Rust 发出的多模态请求；页面无错误。
- 模型测试使用本地模拟服务，未验证真实云模型的识图效果。各平台安装包未逐一实机安装验收。

## 下载

- Windows x64：`x64-setup.exe` 或 `x64_en-US.msi`。
- Linux x64：AppImage、DEB、RPM。
- macOS：根据 Apple Silicon / Intel 选择对应的 `.app.tar.gz`；DMG 若成功生成会一并提供。
