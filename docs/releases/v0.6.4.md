# MarkCaptain 0.6.4

统一应用菜单、编辑器、标题栏和 Muya 界面的快捷键定义，修复源码模式误吞按键、查找替换行为不一致、快捷键录制失败及跨平台按键冲突等问题。

## 统一快捷键注册表

- 新增唯一快捷键注册表，集中声明动作、默认按键、作用域、可用编辑模式、执行所有者、平台限制以及是否允许用户修改。
- Vue 渲染层与 Rust 原生菜单共同读取同一份注册表，避免默认按键、保留键和原生菜单加速键各自维护后逐渐失配。
- 编辑器工具栏、标题栏、写作 Agent、Muya 格式菜单、快速插入和右键菜单统一从注册表生成快捷键提示。
- 移除界面中没有实际执行路径或与应用命令冲突的快捷键提示，显示内容与真实可用行为保持一致。
- 旧版遗留的部分、重复或无效快捷键配置会被确定性修复为完整、非空且无冲突的映射。

## 编辑与查找修复

- 源码模式不再拦截仅适用于所见即所得编辑器的标题、粗体、斜体、链接等快捷键，避免按键被阻止后没有任何响应。
- 撤销、重做和全选仍由当前活动编辑器正确处理，并保留 Windows、Linux 和 macOS 各自的重做习惯。
- `Ctrl/Cmd+H` 现在会直接展开并聚焦替换输入框，不再只打开查找栏。
- 查找栏已经显示时，再次按 `Ctrl/Cmd+F` 会重新聚焦查找框，便于立即开始新的搜索。
- Agent 快捷键、标题栏 `Alt` 访问键及固定编辑命令纳入统一保留校验，用户自定义按键不会再覆盖这些功能。

## 录制与跨平台兼容

- 修复 `Ctrl/Cmd++`、数字键盘、功能键和音量键的识别、保存与显示。
- 支持录制带命令修饰键的 `Tab` 和 `Escape`；单独的 `Tab` 仍用于切换焦点，单独的 `Escape` 仍用于取消录制。
- 录制期间临时释放原生剪切、复制和粘贴加速键，使设置页能够识别这些组合并明确提示它们已被保留。
- macOS 使用 `Cmd` 作为主修饰键，物理 `Ctrl` 不再被误认为 `Cmd`；Windows/Linux 的 AltGr 输入不会误触自定义快捷键。
- 不受原生菜单稳定支持的媒体、浏览器和启动键会在保存前被拒绝，避免出现界面接受但实际无法执行的配置。
- `Ctrl/Cmd+Q` 明确建模为 macOS 系统快捷键，Windows 和 Linux 不再显示或保留不存在的退出快捷键。

## 验证

- 44 个前端单元测试文件、279 项测试通过。
- 115 项 Rust 测试通过。
- 7 项快捷键与 Muya 聚焦浏览器端到端测试通过，覆盖 Muya、源码模式、保存、另存为、查找替换和快捷键录制。
- TypeScript、ESLint、前端生产构建、Rust 格式检查和差异检查通过。
- 浏览器端到端测试不能完全证明打包后的 Windows WebView2/Muda 原生加速键行为；录制期间释放剪切、复制、粘贴及原生菜单长按重复事件仍建议在打包应用中复核。
