# MarkText 0.7.2

修复无认证本地模型被系统凭据库阻断的问题，并让写作 Agent 在后续对话中获得逐项审阅意见。

## 无认证本地模型

- 模型设置新增“无认证本地服务”模式，Ollama 预设默认启用。
- 此模式在读取配置、保存、测试连接和生成时均不访问系统凭据库，不发送密钥或自定义请求头，适用于未安装或未运行 Secret Service 的 Linux 环境。
- 需要密钥或自定义请求头的服务继续使用系统凭据库。凭据库不可用时明确报错，不会降级为明文保存。
- 旧配置默认保留系统凭据库认证；切换到无认证模式不会删除之前保存在系统凭据库中的凭据。
- 凭据库错误提示提供切换无认证本地服务的操作指引。

## 逐项审阅反馈

- 每项修改分配稳定 ID，下一轮逐项发送接受、拒绝、撤回或待审状态，以及对应原文和建议。
- 新增可选审阅意见和“按这个意见重写”，可明确要求针对某项重新提出建议。
- 要求 Agent 保留已接受的修改，不重复提出已拒绝或撤回的其他项；重写仍需用户审阅后才能应用。
- 重写使用应用后的当前文档并保持原修改范围，继续检查文档冲突。
- 启用本地历史后保留修改 ID、审阅状态和意见；旧历史自动补齐 ID，历史修改仍为只读。
- 中文、英文、日文界面同步更新。

## 验证

- 289 项前端单元测试、155 项完整 Rust 测试（含 35 项 Agent 测试）和 30 项 Agent 浏览器流程测试通过。
- TypeScript、ESLint、生产构建、Rust 格式及差异检查通过。
- 覆盖凭据库不可用时无认证模式不调用凭据读写、认证模式失败时报错、真实回环 HTTP 无认证连接，以及逐项反馈、重写和历史迁移。
- 本地验证在 Windows 上进行；浏览器使用模拟模型，HTTP 使用临时本地服务。未进行无 Secret Service 的 Linux 桌面实机及真实模型验收。
