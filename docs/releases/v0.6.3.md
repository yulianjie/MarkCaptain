# MarkCaptain 0.6.3

放宽写作 Agent 的模型服务地址限制，允许连接远程 HTTP 兼容 API，不再强制远程服务使用 HTTPS。

## HTTP 与 HTTPS 接口

- 自定义模型服务现在可以使用任意有效的 `http://` 或 `https://` 基础地址。
- 远程 HTTP 地址不再被设置保存、连接测试或实际对话请求拦截。
- 继续拒绝 `file://`、`ftp://` 等非 HTTP 协议，以及缺少主机的无效地址。
- URL 仍不能嵌入用户名、密码、查询参数、片段或 `/chat/completions` 完整路径，避免凭据混入普通配置或请求地址。
- 设置界面明确提示 HTTP 为明文传输，请仅在可信网络或由用户自行保护的链路中使用。

## 验证

- Rust URL 校验测试覆盖远程 HTTP、回环 HTTP、HTTPS 允许路径，以及非 HTTP 协议与嵌入凭据拒绝路径。
- 259 项前端单元测试、112 项 Rust 测试和 59 项浏览器端到端测试通过；ESLint、TypeScript、Rust 格式检查和前端生产构建通过。
- 使用独立应用标识的 Windows WebView2 原生预览通过：以 `http://<本机主机名>:端口` 保存模型地址，连接测试和实际对话请求均成功，页面错误为零。
- 未使用真实云 API，也未在本次发布前手工安装各平台安装包；平台打包由 GitHub Actions 验证。

## 下载

- Windows x64：`x64-setup.exe` 或 `x64_en-US.msi`。
- Linux x64：AppImage、DEB、RPM。
- macOS：按 Apple Silicon / Intel 选择对应的 `.app.tar.gz`；DMG 若成功生成会一并提供。
