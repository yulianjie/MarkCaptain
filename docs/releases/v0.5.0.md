# MarkCaptain 0.5.0

AI 写作助手新增按需读取和可扩展的技能管理。普通问答不再预先读取文档正文，局部任务可以直接定位并读取相关段落。

## 文档按需读取

- 默认只向模型提供文档名称、行数和大小。助手可先查看提纲、搜索文字，再按行读取相关段落；全文摘要、整体改写等任务仍可显式读取全文。
- 取消「修改前必须读取全文」的工具提示，继续保留选区范围、修改审阅、冲突检查和撤回保护。
- 本地文档快照上限调整为 2 MB，与聊天内容分开计量；单次段落读取最多 200 行/48 KB，过长文档可分段处理。

## 六个内置写作技能

- **团队沟通文档 `internal-comms`**：引入 Anthropic 官方技能及四份参考资料，支持周报、项目进展、FAQ、内部通讯和事故说明，保留 Apache 2.0 许可。
- **Markdown 协作写作 `markdown-coauthor`**：MarkCaptain 自主编写的精简技能，参考文档协作方法，按读者目标起草、局部修订和检查理解难点；减少固定轮次的追问，适配本地编辑器审阅流程。
- **ELI5 通俗解释**：按读者背景解释概念和文档。
- **Mermaid 图表**：辅助编写流程图、时序图、类图与实体关系图。
- **清晰简洁的写作**：精简表达、组织段落和改进可读性。
- **Markdown 说明文档**：按项目和读者需求组织 README。

技能名称和用途参与自动选择；仅在使用时加载正文和参考资料。也可以在输入框上方明确指定技能。

## 用户技能管理

- 点击助手顶部书本按钮，查看、启用或停用技能。
- 通过「导入 SKILL.md」添加本地技能及其 Markdown、TXT、Mermaid 文本参考资料。
- 导入副本和启停状态在重启后保留；删除导入副本不会修改原始技能文件。
- 技能管理支持简体中文、英文、日文、深色主题和窄面板布局。

技能只提供写作方法和文本参考，不会新增脚本执行、任意文件读取或联网权限。社区技能的固定版本、原始许可和参考资料署名均随程序保留。

## 编辑器修复

- 关闭最后一个标签页时正确清空编辑器内容，避免继续显示已经关闭的文档。

## 下载

- Windows x64：`x64-setup.exe` 或 `x64_en-US.msi`。
- Linux x64：AppImage、DEB、RPM。
- macOS：根据 Apple Silicon / Intel 选择对应的 `.app.tar.gz`；DMG 若成功生成会一并提供。

## 验证

前端生产构建、ESLint、技能格式校验、232 项前端单元测试、88 项 Rust 测试和 7 项 Agent 浏览器测试通过。独立 Windows WebView2 预览已验证六个技能的原生 IPC、启停持久化、官方参考资料读取与局部修改建议。

模型测试使用本地模拟服务。系统文件选择器已打开，但自动化授权超时，选择文件并完成导入的原生界面步骤尚未验收；导入数据处理已通过隔离目录和浏览器测试。各平台安装器未逐一实机验收。
