# MarkCaptain 0.3.1

修复 0.3.0 中工具栏按钮过早隐藏、间距过大的问题，并包含 Windows 应用快捷键修复。

## 修复与改进

- **工具栏恢复完整布局**：编辑区宽度达到 700px 时显示完整按钮；约 788px 的常用宽度下不再提前隐藏删除线、代码、任务列表、引用、图片和表格。
- **按钮间距更紧凑**：编辑按钮按固定间距靠左排列，搜索和“更多”保留在右侧，不再将空白平均拉散到各组之间。
- **渐进式窄窗口布局**：先缩小间距与按钮，空间确实不足时再收纳扩展操作；被收纳的操作仍可从“更多”菜单执行。
- **恢复 Windows 应用快捷键**：应用快捷键由渲染层优先处理，避免被编辑器按键映射截获；同时避免长按重复触发。
- 更新设计规范，新增六档编辑区宽度的按钮可见性、间距、溢出和实际操作回归测试。

## 下载

- Windows x64：`x64-setup.exe` 或 `x64_en-US.msi`。
- Linux x64：AppImage、DEB、RPM。
- macOS：Apple Silicon / Intel 对应的 `.app.tar.gz`；DMG 若成功生成会一并提供。

## 验证

前端构建、ESLint、224 项单元测试通过；15 项浏览器回归测试通过，覆盖工具栏、目录、搜索与快捷键。原生安装包构建结果可在本次 Release 工作流中查看，构建成功不等同于所有平台安装器和原生窗口操作的实机验收。
