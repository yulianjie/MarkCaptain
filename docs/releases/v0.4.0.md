# MarkCaptain 0.4.0

新增内置 AI 写作 Agent，让文档阅读、提纲整理、文字润色和续写融入编辑器。修改由你审阅并确认后应用。

## AI 写作助手

- **通用模型接入**：提供 DeepSeek、OpenAI、Ollama 和自定义兼容服务预设，支持配置 API 基础地址、模型名称、密钥以及连接测试。模型需支持 Chat Completions、流式输出和工具调用。
- **顺手的对话体验**：右侧面板支持流式回复、停止生成、失败重试、复制回复和写作快捷指令；每篇文档保留独立的窗口内会话。可从标题栏、「视图」菜单、命令面板或 `Ctrl/Cmd+Shift+A` 打开。
- **明确的上下文范围**：可附加当前文档、仅附加选中内容，或不附加文档；发送前显示选定范围。助手可读取、搜索附加内容，并提出修改建议。
- **先审阅再修改**：对照查看原文与建议，选择应用或忽略；支持撤回和编辑器正常撤销。源码与所见即所得模式均可使用，文档发生变化后会阻止旧建议覆盖新内容。
- **紧凑且可调整的界面**：支持面板宽度调整、窄窗口布局、深色主题，以及简体中文、英文和日文。

## 数据与权限

- API Key 保存于操作系统凭据库，按接口地址隔离；不会写入普通配置文件，也不会回传到设置界面。更换服务地址不会携带原服务的密钥。
- 会话只保留在当前窗口内存中。发送时将选定上下文与该文档已有会话交给配置的模型服务；取消附加文档不会删除此前已发送的会话消息。
- 工具仅能访问附加的文档快照，不包含 Shell、任意文件操作或联网搜索；模型不能直接保存或应用修改。
- 任务具有执行轮数、响应长度和超时限制；取消、截断或失败时不会应用未完成的建议。AI 回复经过安全过滤，不加载远程图片或脚本。

## 开始使用

点击 **AI 助手 → 模型设置**，选择服务并填写自己的模型信息，然后「保存并测试」。DeepSeek 预设使用 `https://api.deepseek.com`；OpenAI 兼容地址通常以 `/v1` 结尾，基础地址不应包含 `/chat/completions`。

本地 Ollama 需先启动服务并下载支持工具调用的模型。Linux 密钥存储需要可用且已解锁的 Secret Service。

[完整使用说明](https://github.com/yulianjie/MarkCaptain/blob/v0.4.0/docs/AI_AGENT.md)

## 下载

- Windows x64：`x64-setup.exe` 或 `x64_en-US.msi`。
- Linux x64：AppImage、DEB、RPM。
- macOS：根据 Apple Silicon / Intel 选择对应的 `.app.tar.gz`；DMG 若成功生成会一并提供。

## 验证

前端构建、ESLint、230 项前端单元测试、80 项 Rust 测试及 30 项浏览器回归测试通过。Windows 独立预览版本还通过了真实 WebView2 中的原生 IPC、系统凭据保存/读取/删除、连接测试、多轮工具调用、修改应用/撤回及取消测试。
