# MarkCaptain 0.8.7

本版修复编辑区 Markdown 链接误开浏览器、同文档章节定位不滚动和链接浮层残留的问题。

## 文档链接

- 按住 Ctrl（macOS 为 Cmd）点击链接，或点击链接浮层的跳转箭头，在编辑器标签页中打开对应 `.md` 文件；已打开的文档复用标签页。
- 相对路径以源文档所在目录为基准，支持 `../`、中文与空格、URL 编码和引用式链接；单独打开文件时也可使用，无需先打开项目。
- `[章节](#标题锚点)` 在当前文件内定位并滚动到对应标题，保留标题格式和 Markdown 正文；支持中文章节名。
- 普通单击保留链接编辑功能，不再被 Tauri shell 插件当成 `tauri.localhost` 网页打开；尝试跳转到缺失文件时，在编辑器内显示错误并保留当前文档。
- 关闭跳转前的链接浮层，取消过期的延迟显示，避免浮层残留遮挡正文或其他链接。
- 所见即所得与源码模式使用相同的本地文档解析逻辑，项目导航保留分栏归属。

## 验证

- 600 项前端单元测试、12 项相关浏览器回归通过；浏览器回归纳入 Tauri shell 外层点击监听行为。
- Windows 原生 WebView2 完成 11 项检查，使用真实 Rust 文件读取和项目索引；IPC 监测确认本地链接操作没有调用系统浏览器打开接口，源文件内容未改变。
- 使用 Windows 桌面鼠标复验文件链接、中文章节滚动和缺失文件处理；普通点击及缺失文件跳转均未增加外部 Edge 标签页。
- 类型检查、ESLint、生产构建及 Windows 原生测试构建通过。macOS/Linux 的安装和实际编辑仍需在对应设备验收。

## 下载与更新

- Windows x64：NSIS `.exe` 或 MSI 安装包。
- Linux x64：AppImage、DEB、RPM。
- macOS：Apple Silicon／Intel 对应的 `.app.tar.gz`，以及成功生成的 DMG。
- 四平台更新包沿用既有 Tauri 更新签名，全部平台构建成功后发布 `latest.json`；`.sig` 和清单无需手动安装。
