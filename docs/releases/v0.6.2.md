# MarkCaptain 0.6.2

为写作 Agent 的兼容 API 增加自定义请求头支持，适配需要租户标识、网关令牌或非 Bearer 认证方式的模型服务。

## 自定义 API 请求头

- 模型设置新增“自定义请求头”，按每行 `名称: 值` 配置，最多 32 项。
- 自定义请求头会用于“保存并测试”以及后续每一次 Chat Completions 请求。
- 支持通过自定义 `Authorization` 使用 Token、Basic 等认证方式；配置后会替代自动生成的 Bearer API Key，避免重复认证头。
- 请求头名称大小写不敏感，值中可正常包含冒号；重复名称、无效格式和控制字符会在保存前被拒绝。
- `Host`、`Content-Length`、`Content-Type`、`Transfer-Encoding` 等由 HTTP 传输层管理的字段不可覆盖。

## 凭据与兼容性

- 请求头内容与 API Key 一同保存在操作系统凭据库，不写入普通配置文件，也不会回传到设置界面。
- 已保存的请求头可保留或单独删除，不会误删同一服务的 API Key。
- 兼容已有版本保存的 API Key，无需升级后重新输入。
- 中文、英文和日文界面均提供配置说明、保存状态及错误提示。

## 验证

- 259 项前端单元测试通过。
- 32 项 Agent Rust 测试通过，真实回环 HTTP 测试确认自定义租户头会发送，且自定义 `Authorization` 会正确替代 Bearer 认证。
- 59 项浏览器端到端测试通过，包括 Agent 设置、自定义请求头保存/删除和修改审阅流程。
- 使用独立应用标识的 Windows WebView2 原生预览通过：系统凭据保存、Header 实际发送、Authorization 覆盖、Header/API Key 独立删除及零页面错误均已验证。
- TypeScript、ESLint、Rust 格式检查、前端生产构建和差异检查通过。
- 未使用真实云 API，也未在本次发布前手工安装各平台安装包；平台打包由 GitHub Actions 验证。
