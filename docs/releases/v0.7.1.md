# MarkCaptain 0.7.1

完善 v0.7.0 引入的云存储工作流，将存储方式明确归属到项目，同时为普通单文件提供安全、显式的一次性云上传入口，并自动识别 Git 项目。

## 项目级存储

- 云存储配置现在以规范化项目目录为单位，同一个项目最多绑定一种存储方式。
- 未配置云存储的普通目录默认保持本地模式，不会因为打开文件夹而自动上传内容。
- 项目侧栏显示当前的本地、Git 或云端模式，并提供项目同步和存储设置入口。
- 修改项目配置后可以通过项目刷新重新解析存储绑定，无需重启应用。

## Git 项目自动识别

- 打开 Git 仓库根目录时，MarkCaptain 会自动识别当前分支和首选远端，默认使用 Git 模式。
- 存在可用远端时会自动建立项目 Git 绑定；优先使用当前 upstream，其次使用 `origin`。
- 没有远端或处于 detached HEAD 的仓库仍会显示为 Git 模式，但不会虚构远端或自动执行网络操作。
- 显式配置的项目存储优先于自动检测，用户仍可删除 Git 绑定后改用其他项目存储。

## 单文件云上传

- 未打开项目目录、只编辑单文件时，默认继续使用本地模式。
- 编辑器工具栏新增云上传按钮，可选择已经配置的非 Git 云目标。
- 上传对话框支持浏览远端目录并选择具体上传位置。
- 上传前先完成本地保存；未命名文档会先进入正常的另存为流程。
- 上传使用 create-only 条件写入。如果远端已经存在同名文件，会报告冲突而不是覆盖。
- Git 仅作为项目级存储，不出现在单文件云上传目标中。
