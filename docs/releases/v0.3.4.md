# MarkCaptain 0.3.4

重新设计编辑器界面，减少边缘留白和顶部占用，让更多空间用于写作。

## 改进

- **更紧凑的布局**：标题栏、页签栏和工具栏合计高度缩至 102px，正文上方与两侧默认留白为 24px；新建页签按钮紧随最后一个页签。
- **适度圆角**：窗口、页签、菜单和输入框采用分级圆角，配合更轻的分隔线与选中状态。
- **清晰的状态栏**：“已保存”和“所见即所得”改为无边框、无底色的只读状态文字，保存状态保留小圆点提示；状态栏横跨窗口底部。
- **更轻的侧边栏**：默认总宽度为 264px，目录标题、搜索框和条目更加紧凑，保留拖动调宽、完整隐藏与恢复。
- **保留个人设置**：已有的正文宽度和侧栏宽度设置继续生效，浅色与深色主题均适配新的布局。
- 新增多窗口宽度、侧栏展开/收起、真实编辑保存状态和源码模式切换的浏览器回归测试。

## 下载

- Windows x64：`x64-setup.exe` 或 `x64_en-US.msi`。
- Linux x64：AppImage、DEB、RPM。
- macOS：根据 Apple Silicon / Intel 选择对应的 `.app.tar.gz`；DMG 若成功生成会一并提供。

## 验证

前端构建、ESLint、224 项单元测试、22 项浏览器回归测试及 Rust 检查通过。原生安装包构建结果见本次 Release 工作流；各平台安装器和原生窗口操作尚未逐一实机验收。
