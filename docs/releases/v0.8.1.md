# MarkCaptain 0.8.1

本版改进人与 Agent 同时编辑的协作体验，增加重复文本的精确修改锚点，并提供默认关闭、显式授权单文档的外部 MCP 接口。

## 正文变化后的重新审阅

- 正文变化后立即标记建议过期，禁用失效的应用、撤回和定位操作。
- 支持按当前授权范围重新生成；旧选区无法定位时，可以重新选择并附加新范围，不会自动扩大为全文。
- 保守三方比较把未冲突的待审修改生成新差异卡，仍需再次确认。例如修改开头后，未变化的结尾建议可以重新审阅。
- 同段变化、重复段落删除、顺序歧义或超出比较预算时明确报冲突。已接受、拒绝或撤回的修改不重新播放；迁移后的旧卡只读。
- 保留多轮迁移关系和历史审阅反馈，相同正文在不同快照版本间继续去重保存。

## 重复文本的精确修改锚点

- 读取片段和逐个搜索命中返回绑定快照的 UTF-16 锚点，可只修改第二个相同句子、列表项或表格值。
- 前后端校验快照、原文、授权范围、Unicode 边界及重叠；无锚点的旧调用仍要求原文唯一匹配。
- 应用仍检查完整编辑缓冲区，锚点不能绕过过期保护。

## 外部 Agent / MCP 首版

- 在 AI 助手面板主动授权当前文档后，本机 MCP 客户端可读取未保存正文、选区和版本，提交建议并查询逐项审阅结果。
- 建议进入现有差异审阅和撤销流程；外部接口没有任意文件读取、直接应用、保存或 Shell 能力。
- 撤权、关闭面板/文档/窗口、切换文档、旧版本和跨文档请求均受到保护；撤销回相同正文也不能复用旧版本。
- 适配脚本随应用打包，需要 Node.js 18 或更高版本。使用本机随机端口和临时内存凭据，支持请求边界、并发限制、超时及 stdio 背压。
- 接入步骤、工具参数和权限边界见 [MCP 文档](https://github.com/yulianjie/MarkCaptain/blob/v0.8.1/docs/EXTERNAL_AGENT.md)。外部重新生成由客户端重新读取并提交。

## 构建维护

- `src-tauri/icons/` 改为自动生成目录并从 Git 跟踪中移除，保留原始图稿及单独维护的 Markdown 文件关联图标。
- 原生开发、生产构建和 Rust CI 均在需要时生成图标；直接使用 Cargo 前需先运行 `npm run icons:bundle`。
- 修复 Windows 打包资源的扩展路径不能作为 Node 脚本启动入口的问题。

## 验证与范围

- 325 项前端单元测试、166 项 Rust 测试及 39 个 Agent 浏览器场景验证通过。
- 类型检查、生产构建、ESLint 和差异检查通过；所有 52 个生成图标都已通过源图稿重建检查。
- Windows 独立 WebView2 预览验证了打包 MCP、未保存正文与选区、两种编辑模式的重复文本锚点、审阅/撤销、重新审阅结果回传、冲突、旧版本、跨文档及撤权，页面错误为 0。
- 三方比较采用保守段落对齐，可能拒绝仍可人工合并的字符级修改。未分别连接实际 Codex/Claude 客户端或真实云模型；Linux/macOS 桌面实机与安装器未手动验收。

## 下载

- Windows x64：NSIS `.exe` 或 MSI。
- Linux x64：AppImage、DEB、RPM。
- macOS：Apple Silicon / Intel 对应的 `.app.tar.gz`；DMG 若成功生成会一并提供。
