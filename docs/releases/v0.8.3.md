# MarkCaptain 0.8.3

本版补齐日常笔记工作流：快速打开、模板与每日笔记、分屏布局、本地历史、内部链接与反链、移动引用维护、标签属性和结构化搜索。普通 Markdown 文件继续可由其他编辑器使用，Agent 仍按附加文档、快照校验和审阅后应用的机制工作。

## 日常笔记

- 快速打开支持文件名、相对路径及 YAML 别名模糊搜索；空查询显示最近笔记，同名结果显示目录。支持键盘选择、打开、新标签和创建缺失笔记。快捷键：`Ctrl/Cmd+K`。
- 文档模板与 Agent 写作技能分别管理。模板支持标题、日期、时间变量，内置会议、读书和工作日志示例，插入到发起操作的区域与光标。快捷键：`Ctrl/Cmd+Alt+T`。
- 一键打开今天的笔记，可配置日期格式、目录及模板；已有内容直接打开，新建失败不会留下部分文档。快捷键：`Ctrl/Cmd+Alt+D`。

## 分屏与版本

- 左右／上下分屏，最多四个区域；文档内容、脏状态、保存队列和撤销共享，光标、选区及源码模式独立。支持调整大小、命名布局和会话恢复。
- Agent 文档、选区、引用定位及应用目标跟随活动区域。切换区域及异步读取后重新校验目标，拒绝陈旧 Muya 事件覆盖新内容。
- 本地历史独立于云同步、Agent 对话和崩溃草稿。提供版本列表、差异、复制、恢复为新文档及恢复当前文档；恢复前必须成功保护未保存内容，恢复后可撤销。默认间隔 60 秒、保留 30 天、空间 256 MiB。

## 链接、属性与搜索

- 支持 Wiki 链接、显示文字、标题锚点及标准 Markdown 内部链接，包括引用式链接；补全、跳转、创建缺失目标、反向链接和未链接提及共用项目索引。同名歧义需要完整路径，代码示例不计入链接。
- 应用内移动／重命名预览引用更新，保留显示文字、锚点、编码、BOM 和换行。提交前排空保存并检查完整 Markdown 文件清单与字节哈希；备份原始字节，冲突拒绝覆盖，可恢复事务并同步打开的文档。
- 正文标签与 YAML `tags`、`aliases` 合并索引，支持嵌套标签统计及筛选。基础属性支持文本、列表、数字、布尔值、日期；复杂或无法无损显示的 YAML 值保留在源码编辑，相同值保存保留原始格式。
- 结构化查询支持 `name:`、`path:`、`tag:`、`prop.key:`、`task:open|done|any` 及 AND／OR／NOT。任务跨文档汇总，点击定位，修改经过正常编辑、撤销与保存。索引及查询在后台执行，可取消和重建。

## 验证与使用边界

- 399 项前端单元测试、184 项 Rust 测试、89 项浏览器 E2E 通过；类型检查、ESLint、Rust 格式与编译检查、生产构建通过。
- Windows 原生验证覆盖中文及同名路径、分屏源码／可视化选区重启、未保存草稿、外部修改、历史保护恢复、引用事务与回滚、1200 文件索引，以及 Agent 应用 → 撤销 → 重做 → 再撤销 → 继续对话。原生 Agent 模型响应使用本机测试服务，文件操作与工具循环使用真实 Rust。
- 单文件索引／历史正文上限 4 MiB，项目索引正文 128 MiB，引用事务正文 64 MiB，搜索／任务最多显示 1000 条。复杂 YAML 在源码编辑；历史按路径归档，当前没有浏览已移除路径归档的入口。外部移动更新索引，不自动改写引用。
- 跨进程最终检查与写入并非系统级原子锁。macOS／Linux 桌面安装启动及真实商业模型未实测；各平台构建和安装包以本次发布工作流结果为准。
