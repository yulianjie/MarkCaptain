# MarkCaptain 0.3.0

本次更新重新设计编辑器界面，带来更清晰的文章目录和轻盈的毛玻璃效果。

## 新功能与改进

- **统一 Windows 顶栏**：应用标题与菜单合并为一行，移除顶部文章路径；保留原生菜单内容、快捷键和窗口控制。
- **全新文章目录**：标题级别标签、层级引导线、分支折叠与当前章节高亮，支持标题搜索、键盘导航和正文定位。
- **实时阅读进度**：根据正文实际滚动位置计算，切换文章时重置目录搜索与折叠状态。
- **毛玻璃界面**：侧栏、顶栏、标签栏、工具栏与状态栏采用半透明磨砂材质，正文保持清晰易读；适配深色主题与降低透明度设置。
- **保留独立搜索入口**：窄窗口下工具栏仍显示正文搜索按钮，查找/替换面板可在编辑区内换行布局。
- 新增 `DESIGN.md`，记录设计规范、交互规则与实现入口。

## 下载

- **Windows x64**：选择 `x64-setup.exe` 或 `x64_en-US.msi`。
- **Linux x64**：提供 AppImage、DEB 和 RPM。
- **macOS**：按 Apple Silicon / Intel 选择对应的 `.app.tar.gz`，解压后使用；DMG 若成功生成会一并提供。

合并顶栏针对 Windows；macOS 和 Linux 继续保留原生标题栏与菜单。毛玻璃为应用内部的 WebView 效果，不透出桌面壁纸。

## 验证

前端构建、ESLint、207 项单元测试、13 项浏览器测试及 Windows Rust 编译检查通过。浏览器测试覆盖目录搜索、折叠、定位、阅读进度和 800px 深色窗口的搜索交互；不代表已完成所有平台的原生窗口操作与安装器实机验收。
