# MarkCaptain 0.8.11

本版修复 Windows 使用 Git 存储时的控制台闪窗，并让已保存的修改可以在应用内确认、提交并同步。

## Git 存储

- Windows 上的 Git 仓库识别和同步以无控制台窗口的方式运行。
- 项目侧栏和云存储设置中的「立即同步」会列出待提交文件、仓库和目标分支，取代未提交修改触发的 `git:unsafeState` 报错。确认「提交并同步」后，应用会重新核对同步目标，再创建提交。
- 同步支持快进拉取和普通推送。两端历史分叉时可以准备审阅式合并。部分暂存的文件需先用 Git 处理暂存内容。
- 中文、英文、日文界面显示本地修改、同步结果和相关 Git 操作提示。

## 验证与下载

- 在 Windows 桌面版中验证 `note-test` 的文件清单与取消流程，并在本地镜像中验证推送修改、新增文件和快进拉取。
- 提供 Windows x64、Linux x64、macOS Apple Silicon 与 Intel 下载包。四个平台的更新包均通过签名校验后，发布包含下载地址和签名的 `latest.json`。
