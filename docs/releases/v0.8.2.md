# MarkCaptain 0.8.2

本版修复 macOS 启动后 Dock 中有应用图标、主界面却不显示的问题。

## 启动窗口修复

- 首次显示改为在偏好加载、界面挂载和 Vue DOM 更新完成后直接调用原生窗口显示命令，不再等待 `requestAnimationFrame`。隐藏的 macOS WebView 即使暂停动画帧，也不会阻止这一步显示。
- 保留首次显示前的窗口位置恢复，以及正常启动时的语言、主题预加载。
- 初始化失败时记录错误并继续尝试挂载；挂载失败时仍尝试显示原生窗口。显示命令失败也会记录错误，避免未处理的启动 Promise 异常。
- 此启动路径适用于主界面、新建编辑器窗口和设置窗口。

## 验证

- 334 项前端单元测试通过，包含新增的 9 项启动回归测试，覆盖不触发动画帧、偏好和 DOM 更新等待、初始化及显示失败、浏览器开发模式。
- 7 项浏览器 E2E 通过，覆盖编辑器启动、设置页面、命令面板、源码模式及撤销/重做。
- 类型检查、生产构建、ESLint 和差异检查通过。
- 隐藏 WebView 的动画帧阻塞条件通过模拟验证；macOS 桌面实机启动及安装尚未手动验收。

## 下载

- Windows x64：NSIS `.exe` 或 MSI。
- Linux x64：AppImage、DEB、RPM。
- macOS：Apple Silicon / Intel 对应的 `.app.tar.gz`；DMG 若成功生成会一并提供。
