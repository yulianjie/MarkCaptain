# MarkCaptain v0.1.6 — 现代编辑工作流与可靠性升级

v0.1.6 是一次面向日常写作体验与数据可靠性的集中升级。本版本补齐了顶部快捷工具栏、状态栏、命令面板、完整项目树操作、源码模式编辑能力、会话恢复和外部文件变更处理，并加强了工作区文件操作与搜索的安全边界。

## 主要新增

### 编辑器工具栏与状态栏

- 新增顶部快捷工具栏，提供：
  - 撤销与重做
  - 正文及 H1–H6 标题切换
  - 粗体、斜体、删除线、行内代码
  - 链接与图片
  - 无序列表、有序列表、任务列表、引用、代码块和表格
  - 查找、源码模式、专注模式和打字机模式
- 工具栏在窄窗口下支持横向滚动，所有按钮提供键盘焦点和无障碍标签。
- 新增底部状态栏，实时显示：
  - 文件编码、BOM 和换行符
  - 字数、字符数和段落数
  - 已保存/未保存状态
  - 自动保存状态
  - 所见即所得/源码、专注和打字机模式
- 工具栏和状态栏均可通过“视图”菜单或命令面板独立显示、隐藏，设置会被持久化。

### 命令面板与菜单

- 新增 `Ctrl+Shift+P` 命令面板，统一访问文件、编辑、段落、格式、视图及帮助操作。
- 支持按标题、说明、命令 ID 和关键词进行模糊搜索。
- 不可用命令会明确显示为禁用状态，不会被误执行。
- 支持完整键盘导航、ARIA combobox/listbox 语义，以及简体中文、英文和日文界面。
- 补齐原生菜单到编辑器动作的显式映射，工具栏、命令面板和菜单共用相同的执行路径。

### 项目树与工作区搜索

- 项目树新增：
  - 新建文件和文件夹
  - 重命名
  - 复制、剪切和粘贴
  - 复制路径
  - 移至系统回收站
- 打开工作区时只读取根目录，文件夹在展开时按需加载，减少大型目录的启动开销。
- 并发展开会自动去重；加载失败的目录可以直接重试。
- 文件名过滤能够按需递归加载尚未展开的目录，并提供取消、错误和重试状态。
- 工作区全文搜索现在会返回每个文件中的全部匹配项，并正确处理 Unicode、CRLF 和非 BMP 字符坐标。
- 单击搜索结果会打开对应文档，在当前编辑模式中精确选择、居中并聚焦匹配内容。

### 源码模式与编辑体验

- 源码模式现在为每个标签独立保存 CodeMirror 编辑状态、选择位置及撤销/重做历史。
- 支持源码模式查找、替换、正则表达式、大小写和全词匹配。
- 源码编辑会实时更新状态栏字数、字符数和段落数。
- 改善源码模式与所见即所得模式之间的内容和选择状态同步。
- 新增右键拼写检查建议、单词替换及加入用户词典操作。
- 图片可按 Markdown 文件位置生成可移植的相对链接，支持 Windows 驱动器、UNC 和 POSIX 路径，并正确编码空格、Unicode、`#` 和 `%`。
- 新增四种末尾换行策略：
  - 移除所有末尾换行
  - 确保恰好一个末尾换行
  - 保留文件原有样式
  - 不调整末尾换行
- 末尾换行策略仅在保存边界应用，不会在输入过程中吞掉用户编辑的空行。

## 可靠性与安全性

- 新增完整会话及异常退出恢复，可恢复：
  - 工作区
  - 标签顺序和活动标签
  - 未保存草稿
  - 光标及源码选择
  - 每个标签的编辑模式
- 正常退出不会重新弹出已丢弃的草稿；旧版会话中缺失的末尾换行策略会使用兼容默认值。
- 关闭窗口、批量关闭标签或删除包含已打开文档的目录时，会先完成保存、不保存或取消决策；取消、保存失败或保存期间发生新编辑时，不会提交部分关闭结果。
- “另存为”改为事务式处理：目标写入、外部冲突确认或文件选择失败时，保留原标签身份和草稿。
- 外部文件发生修改、删除或重命名时：
  - 未修改标签可安全重新载入
  - 本地有修改时会要求用户明确选择
  - 被删除的文档保留为脱离磁盘的未保存标签
  - 目录重命名会同步更新所有子文档路径
- 外部删除确认期间会暂时阻止自动保存，避免内容被写回已经失效的旧路径。
- 多窗口共用工作区监听器；只有最后一个使用者关闭后才停止监听，并向对应窗口发送定向事件。
- 工作区文件操作使用规范化路径边界：
  - 拒绝跳出当前工作区
  - 拒绝字符串前缀碰撞
  - 拒绝符号链接逃逸
  - 拒绝覆盖已有目标
  - 拒绝将目录复制或移动到自身后代
  - 失败的递归复制会清理不完整目标
- 搜索只接受当前已打开的工作区根目录，并剪除指向工作区外部或形成循环的符号链接。

## 导出与兼容性

- PDF/HTML 导出界面现在明确区分三种流程：
  - **系统打印**：打开操作系统打印对话框，可从中选择“另存为 PDF”，不需要 Pandoc。
  - **Pandoc PDF**：直接生成 PDF 文件，需要系统已安装 Pandoc 和兼容的 PDF 引擎。
  - **Styled HTML**：导出带样式的 HTML，不需要 Pandoc。
- Pandoc PDF 失败后会显示实际错误，并询问是否切换到系统打印，不会静默改变导出方式。
- 保留原有通过 Pandoc 导出 DOCX、ODT 和 EPUB 的入口。
- 本版本没有修改上游 Muya 编辑器目录，降低与既有 WYSIWYG 行为的兼容风险。
- 自动更新插件已经注册，且更新地址已指向本仓库；但当前版本仍采用安全关闭策略：
  - `plugins.updater.active` 默认为 `false`
  - 尚未配置签名公钥
  - 当前发布流程尚未生成签名更新包和 `latest.json`
  - 因此“检查更新”会明确显示自动更新未启用，不会进行网络检查，也不会把未检查状态误报为“已是最新版本”

## 升级说明与已知限制

- 升级后顶部工具栏和状态栏默认显示；如不需要，可从“视图”菜单或命令面板关闭。
- 现有偏好设置会被保留。
- 末尾换行默认采用“保留文件原有样式”，不会主动改变已有文档格式。
- 直接生成 Pandoc PDF、DOCX、ODT 或 EPUB 仍要求 `pandoc` 位于系统 `PATH` 中；PDF 还需要兼容的 PDF 引擎。
- 自动更新目前默认关闭，本版本仍需从 GitHub Release 页面手动下载安装。
- 状态栏当前是只读信息栏，暂不提供行列位置，以及点击切换编码或换行符的功能。
- 多窗口监听和会话恢复逻辑已由单元测试及 Rust 测试覆盖，但真实双窗口 Tauri GUI 的崩溃恢复流程尚未纳入自动化 E2E。
- 本版本尚不包含分屏编辑、单窗口多工作区、工作区级 `markcaptain.json` 配置、Backlinks 或知识图谱。
