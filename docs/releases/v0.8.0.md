# MarkCaptain 0.8.0

MarkCaptain 正式启用独立品牌与安装身份。这不仅是名称更新：应用、安装器、数据目录、凭据、文件关联、发布流程、项目文档和 GitHub Wiki 已统一迁移到 MarkCaptain，使其可以与原应用并行安装。

## 独立应用与安装身份

- 产品名、窗口标题、Node/Rust 包名和主程序统一为 MarkCaptain / `markcaptain.exe`。
- Bundle Identifier 改为 `io.github.yulianjie.markcaptain`，设置、单实例锁和系统凭据不再与其他应用共用。
- Windows 使用独立的 `MarkCaptain.Markdown` ProgID 和新的 WiX 组件 GUID；NSIS、MSI 与卸载注册表项均指向 MarkCaptain。
- Linux Desktop/AppStream 元数据、macOS 应用包、安装资源、图标资源文件名和发布资产统一采用 MarkCaptain。

## 项目与文档

- GitHub 仓库迁移到 [`yulianjie/MarkCaptain`](https://github.com/yulianjie/MarkCaptain)。
- 中英文 README、Wiki、历史发布说明、Agent/存储/更新文档和界面文案完成品牌迁移。
- 项目介绍突出本地优先、审阅优先的写作 Agent；仅在 Muya 来源、真实依赖名和法定许可证署名中保留必要的上游名称。
- 帮助菜单、问题反馈、更新源和项目链接全部指向新的 MarkCaptain 仓库。

## 编辑与 Agent 能力

- 延续 v0.7.3 的完整编辑器、项目管理、本地优先存储和多语言界面。
- 写作 Agent 支持按需文档读取、选区约束、多处修改审阅、撤销/重做状态同步、长文总结、图片输入、引用和可选本地历史。
- 模型输出仍需人工审阅；Agent 不具备通用文件系统、Shell、Git 提交、联网搜索或绕过审阅直接保存的能力。

## 验证

- 298 项前端单元测试与 157 项 Rust 测试通过。
- TypeScript、生产构建、ESLint、Rustfmt 和差异检查通过。
- Windows 隔离 NSIS 构建成功，生成 `MarkCaptain_0.8.0_x64-setup.exe`；生成脚本确认产品名、主程序、Bundle Identifier、安装目录、卸载键和文件关联均为 MarkCaptain。
- 发布工作流继续构建 Windows x64、Linux x64、macOS Apple Silicon 与 Intel 安装包。

## 下载

- Windows x64：NSIS `.exe` 或 MSI。
- Linux x64：AppImage、DEB、RPM。
- macOS：按 Apple Silicon / Intel 选择对应的 `.app.tar.gz`；DMG 若成功生成会一并提供。
