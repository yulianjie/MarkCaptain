# MarkCaptain 0.8.5

本版完善本地文档编辑与侧边双链，加入受控的项目资料和多文档 Agent 修订，并提供主题化导出、项目批量输出与合并成册。

## 本地文档与双链

- 左侧保留文件导航，右侧文档检查器集中展示大纲、双链和 Agent；双链可固定，与 Agent 同时查看。
- 反向链接、未链接提及和当前文档链接按来源分组，支持筛选、上下文、分屏定位和返回原位置，已有文件的未保存缓冲区参与分析。
- 统一选区菜单、编辑器右键、命令面板和 Agent 写作操作入口；选择操作后先填入草稿，由用户发送。
- 修复系统文件关联打开的启动时序：编辑器准备完成前保留待打开文件，避免启动期间丢失打开请求；区分笔记本与大纲图标。

## 可控的 Agent 工作流

- 展示模型服务、本轮目标与实际读取的资料；提供可读差异和原始 Markdown 差异，支持中文与结构化内容审阅。
- 项目只读字面搜索需要显式授权，可配置包含/排除范围；打开的未保存文档优先于磁盘，来源正文按需读取。
- 项目写作规范保存在 `.markcaptain/agent.json`，可检查标题层级、本地链接/图片和术语；模型检查为只读，修订仍生成审阅建议。
- 联网研究默认关闭，查询词逐条批准后才发送；配置文件不会自动授予网络或文件权限。
- 本地聊天历史恢复补齐任务身份、审阅状态和引用边界，防止历史建议覆盖当前文档。

## 多文档修订

- 显式选择 1–8 个打开文档，包括未保存缓冲区与未命名文档；每份最多 2 MB、合计 4 MB，元数据先发送，正文按需读取。
- 按文件审阅、应用、忽略和撤回；每份文档保留正常撤销/重做，不提供跨文件全局撤销。
- 应用只修改编辑器缓冲区，所选文档暂停自动保存，用户逐个手动保存；只读原文副本保留在本次会话中，不进入普通聊天历史。
- 应用前重查磁盘指纹、标签/路径/编码、窗格身份与保存队列；外部修改或等待期间的编辑、切换、保存使旧操作失效。
- 修复混合源码/所见即所得模式、特殊编码、Muya 末尾换行和手动保存并发边界；模型不能修改未选文件或只读参考。

## 主题化导出与项目交付

- HTML、系统打印/PDF、DOCX、ODT、EPUB 使用统一导出窗口，提供简洁阅读、技术文档、正式报告三套主题和排版预设。
- 冻结未保存正文生成独立预览，检查资源、链接和转换依赖；字体、公式、图表、长代码和宽表按格式处理，预览中的锚点不再导航到应用页面。
- 项目预设保存于 `.markcaptain/export.json`，支持项目输出目录、选定来源与显式章节顺序。
- 批量导出显示逐项结果，支持取消、部分失败和版本检查后重试；合并成册处理章节锚点、跨章链接、资源和脚注冲突。
- 导出不自动保存源文档，也不默认下载远程资源；不会将打开打印对话框报告为已保存 PDF。

## 验证与使用边界

- 发布前 583 项前端单测、273 项 Rust 测试通过（另 1 项公网 probe 默认忽略）；类型检查、ESLint 和生产构建通过。
- 浏览器完整运行 140 项通过，1 项被开发热更新打断；冻结源码后该项及相关 36 项回归全部通过。
- Windows 原生覆盖真实 WebView2、Rust 文件操作、双编辑模式、独立撤销、磁盘冲突、取消与版本探针竞态；多文档验收 7 场景、15 项检查通过，另完成 Windows 原生窗口与按键复核。
- Pandoc 格式需要本机安装 Pandoc；PDF 另需可用引擎。系统打印的最终分页与保存由系统对话框负责，EPUB 的显示由阅读器决定。
- 多文档原文副本仅保留当前会话，不能替代磁盘备份或跨重启恢复。真实云模型效果及 macOS/Linux 实机编辑、安装升级需在对应环境确认；四平台构建、下载和签名以发布资产核验为准。
