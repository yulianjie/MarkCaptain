# 日常笔记功能复核

2026-10-15，基于当时未提交的八项功能实现。四个子 agent 分别检查区域与 Agent、链接与引用事务、Rust 文件和历史安全、模板与结构化搜索；主 agent 复核源码、回归测试与原生流程。评审阶段没有提交、推送或发布；后续 0.8.3 发布说明见 [版本说明](releases/v0.8.3.md)。

## 修复的主要问题

| 范围 | 实证问题与处理 |
| --- | --- |
| 分屏与 Agent | 新区域尚未就绪时保留旧 Muya 句柄，可能把旧光标用于新文档；切换先清旧句柄，由所属区域登记实例。异步引用定位重验发起区域和文档。 |
| 区域状态与撤销 | 外部重载后区域缓存和共享撤销仍可带回旧状态；文档重置统一失效全部区域缓存并清共享历史。未就绪的处理器不再吞撤销步骤。非活动区域不再清活动格式菜单。 |
| 会话布局 | 会话跳过缺失文件后按压缩标签索引绑定到了其他文档；恢复使用原会话索引到标签 ID 的映射，缺失的已保存文档恢复为空区域。空区域布局不再产生无法解析的负索引。 |
| 独立视图恢复 | 各区域的光标与源码选区现在随布局保存，仅保存文档范围内的轻量位置，拒绝越界及拆开 UTF-16 字符的位置；源码和可视化的双区域位置均通过真实 Windows 重启验证。 |
| 迟到的 Muya 事件 | 生产原生验证发现新建内容立即分屏输入会被隐藏 Muya 的延迟解析通知覆盖。隐藏源码区域不接收 Muya 内容；每个可视化区域按自己的文档基线拒绝陈旧事件，真实首击不会被误标为已保存。 |
| 引用事务 | 确认时新开的脏文档漏检，在途保存可竞争；事务先暂停编辑、排空保存与外部队列，再重取全部缓冲区、重建并核对预览。异步打开也拒绝跨事务或跨区域的旧读取。 |
| 引用外部变化 | 原后端只校验需要改写的文件，遗漏移动源、未改写文档和文件增删；现在校验完整 Markdown 文件清单及字节哈希，复用扫描过滤规则。 |
| 引用恢复 | 依赖文件监听才能还原标签路径与正文；恢复 IPC 返回确定的路径映射和正文，前端立即同步，不依赖监听是否送达，包括 Windows 大小写／斜杠不同的路径拼写。目标被外部占用导致移动失败时只回滚引用，保留外部目标。 |
| 链接 | 歧义目标曾计入多个反链；仅唯一解析的目标计入反链。引用式链接现在定位实际使用处，并去重改写共享定义。明确扩展名、大小写、Markdown 转义和实体、重复标题、移动后的邻目录同名目标及缺失相对目标均增加回归。 |
| 本地历史 | 损坏或缺失的去重正文曾被当作保护成功；强制保护校验并修复正文后才允许恢复。恢复在确认及保护快照的异步边界后重验 ID、路径、正文和外部冲突。崩溃遗留的临时文件不再阻断清理；版本 ID、元数据文件名和正文 ID 均校验后使用，拒绝越界路径。 |
| 新建笔记 | 写入失败可能留下部分每日笔记；先写同目录临时文件并同步，再以禁止覆盖方式发布。故障测试确认无残留目标和临时文件。 |
| 模板与项目设置 | 异步模板读取后可能插入另一区域或新光标；固定区域、模式、文档、正文和光标。项目切换不再污染新项目的配置或创建目标，每日命令读取目标项目配置，避免使用仍在加载时的旧缓存；配置读取失败不会创建笔记。解码错误拒绝插入，目录尾分隔符统一规范化。 |
| YAML 属性 | 列表子项的锚点、标签、别名及注释会被序列替换丢弃；此类字段只读，多行及列表特殊项同样留在源码编辑。保存相同值保留原始格式，其他属性仍可编辑。Alias 展开受限，不再拖垮整批索引。 |
| 搜索与错误 | 取消只忽略结果，旧结果仍显示；工作线程分批让出执行权并响应取消，清过期结果，错误有三语文案。取消初次扫描会中止引用移动，取消或切换项目清理旧错误。事务失败错误只含恢复状态及 ID，不包含备份正文。 |

## 验证与范围

主 agent 的最终检查结果见 [实施与验证记录](NOTEBOOK_VALIDATION.md) 的 2026-10-15 复核记录。浏览器测试使用真实 Vue、Muya、CodeMirror 与状态逻辑，替换桌面传输边界；Windows 原生验证使用独立应用标识、WebView2 目录和项目夹具，真实 Rust IPC 与磁盘操作，仅 Agent 模型响应使用本机测试服务。

仍需明确的边界：历史按路径归档，旧路径移除后旧归档仍保留，但当前界面没有浏览孤立归档的入口；期限和空间策略仍会清理它们。跨进程最终检查和写入之间不能构成操作系统级原子锁，冲突检查和原始字节备份用于拒绝已发现的变化及恢复。macOS、Linux 原生和安装器流程未验证。
