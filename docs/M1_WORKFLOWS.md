# M1：本地文档、双链、Agent 与导出

本指南对应 M0/M1 开发工作区。项目检索、联网研究、批量导出、合并成册与多文档 Agent 修订属于后续阶段，不会因本次升级自动获得权限。

## 文档检查器

左侧保留文件与搜索导航，右侧检查器提供大纲、双链与 Agent。关闭检查器后可通过右侧图标栏重新打开；窄窗默认收起，手动打开时以浮层显示。

双链页展示目标文档、反向链接、未链接提及和当前文档链接。结果按来源文件分组，可筛选、展开上下文、固定目标，在当前或另一分屏定位，并返回原文档和光标。固定双链区域后，可与 Agent 上下并用。

已有路径的未保存文档参与关系分析；未命名文档不能虚构项目链接身份。索引中、索引不完整和没有关系分别显示。

## Agent

选区菜单、编辑器右键、命令面板与 Agent 内的写作操作共用入口，包含润色、精简、续写、翻译、解释、术语和结构检查。选择操作会填入草稿，不自动发送。

面板显示本轮目标、选区范围、授权参考、模型地址与实际读取的资料。这里的“本地资料”不代表模型离线：配置远程服务时，实际读取的片段会发送给该服务。

修改继续先审阅后应用。差异视图细化中文变化、显示链接目的地，并提供表格、代码和 Frontmatter 的辅助查看；原始 Markdown 始终可看。正文附近的差异预览是只读浮层，不写入正文、不触发保存，也不进入导出。

文档改变后重新校验建议；目标区域冲突时不会猜测应用。应用、撤回和编辑器撤销/重做继续同步审阅反馈。历史开关沿用现有设置，本次没有启用新的跨重启自动执行或全文存档机制。

## 编辑区文档链接

普通点击 Markdown 链接可继续编辑；按住 Ctrl（macOS 为 Cmd）点击，或使用链接浮层的跳转按钮，可在编辑器中打开目标文档。相对路径以当前文档所在目录为基准，支持 `../`、中文、URL 编码和标题锚点；单独打开文件时也可使用，无需先打开项目。打开失败时显示错误并保留编辑器，不会跳转到 `tauri.localhost`。网页链接仍由系统浏览器打开。

## 统一导出

HTML、打印/PDF、DOCX、ODT 与 EPUB 的菜单统一打开导出窗口：

1. 选择格式、主题和排版设置。
2. 点击预览，冻结发起时的文档缓冲区，包含未保存修改。
3. 检查资源、依赖和警告；编辑文档或更改设置后刷新过期预览。
4. 选择输出文件或打开系统打印。导出不会自动保存源文档。
5. 可将设置保存为个人默认或项目预设。

预览同时冻结文档、格式、项目范围与全部排版选项。第一次生成尚未完成时修改设置也会使该次结果失效；导出不会混用旧预览和新设置。选择保存路径、等待预检或写出期间均可取消，关闭导出窗口也会终止尚未发起的后续步骤。

三套浅色主题为简洁阅读、技术文档、正式报告。编辑主题与导出主题独立，纸张、边距、字体别名、字号、行距、目录和编号按实际格式能力生效。

HTML/打印使用禁止脚本的独立 iframe，内容不包含应用工具栏、光标和 Agent 标记。公式字体内嵌；图表静态渲染后输出。普通正文 Wiki 链接转成可点击链接，同文档标题映射到实际锚点；单文件未打包的跨文档目标会提示。

预览中的同文档锚点在正文内滚动，不会导航到应用页面。外部网页和其他文件的链接不在预览中打开；实际导出文件保留这些链接。

### 资源

- 本地图片按源文档位置和项目范围解析，单资源最多 16 MiB；源文档必须已在本进程读取或保存授权。
- HTML 支持图片内嵌与资源目录两种模式；资源目录使用任务独立名称，避免覆盖旧 HTML 所引用的文件。
- 远程图片不会在预览或 Pandoc 转换中自动请求。HTML 保留外部引用时仍依赖网络，不应称为完全离线自包含。
- M1 不提供远程资源下载开关的实际下载能力，启用该项会阻止导出并解释。
- 资源加载属性在 HTML 插入活动页面前即被隔离。PlantUML、带外部资源或自定义配置的 Mermaid 会保留可读源码并提示；Vega 禁止加载外部数据与图片，内联数据图表仍可渲染。这些图表不会借预览调用远程渲染服务。
- 输出限于已打开项目配置的输出目录，或保存对话框批准的路径；不允许覆盖源文档。

### PDF 与其他格式

系统打印不依赖 Pandoc，最终分页和保存位置由系统负责；“已打开打印对话框”不代表 PDF 已保存。

Pandoc 格式需要本机 Pandoc。PDF 另需可用引擎，目前探测 XeLaTeX、Typst、WeasyPrint；实际排版随引擎变化。DOCX/ODT 使用从 Pandoc 默认参考文档派生的格式样式，EPUB 使用 CSS；不能将 HTML 样式逐像素复制到所有格式。

Pandoc 使用同一份资源处理后的 HTML，避免从原始 Markdown 绕过图片范围或 Frontmatter 外部资源控制。浏览器预览对这些格式是内容近似预览，最终文件需要在目标阅读器中确认。缺少依赖或转换失败会报告错误，可显式选择系统打印。

格式转换会使用独立 XML 图表快照，并保留公式的 MathML 语义；HTML 继续使用内联图表和 KaTeX 显示。Typst 的长表允许跨页，DOCX/ODT 通过参考文档映射字体、颜色和页面参数。DOCX/ODT 未映射的行距设置在界面禁用；EPUB 的最终分页由阅读器决定。

超过 8 列的表格会显示布局警告。自动换行不能保证纵向纸张仍易读；请选择横向、调整字号或拆分列，并检查最终文件。本轮 12 列样例使用 A4 横向、10pt 后可读；纵向版本保留内容，但长标识会产生大量换行。

## 项目导出预设

配置保存在 .markcaptain/export.json，不要求手动编辑。保存预设不会自动开始导出。

有效值依次来自：内置默认 → 个人默认 → 项目预设 → 本次调整。界面区分设置来源；只有保存到项目时才写入配置。项目路径采用相对路径，默认输出目录为 exports。

配置使用 schemaVersion 1，默认预设与 profiles 包含主题、格式、排版、纸张、目录、输出和资源策略。保存前校验 fingerprint；外部修改后需重新加载，避免覆盖。未知字段会保留，不支持的新版本会明确提示。

所有配置输出目录会在项目笔记枚举时排除。没有项目时使用个人默认和保存对话框。
