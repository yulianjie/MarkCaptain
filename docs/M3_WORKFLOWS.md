# M3：项目批量导出与合并成册

本轮对应实施方案 E04/E05。项目导出复用 M1 的主题、资源预检和实际文件写出；项目文档仍是本地 Markdown，导出不保存编辑缓冲区。A07 多文档 Agent 修订按方案留待后续独立交付。

## 使用入口

打开本地项目，选择现有“导出 HTML”等入口，在单篇导出窗口中点击“导出项目…”。项目窗口提供两种模式：

- 分别导出文档：每篇文档、每种所选格式生成一个文件，显示实际文件名、逐项状态和错误。
- 合并成册：按显式章节清单生成一本书，每种所选格式各生成一个文件。

选择候选文档，必要时用路径筛选；选择顺序就是默认章节顺序，可上移、下移或移除，修改章节名称和标题层级。未命名标签可以加入当前任务，但不会保存为项目章节路径。最多选择 64 篇；不会把目录遍历顺序当作成册顺序。

选择项目预设或内置主题、格式、输出规则后，先点击“冻结快照并审阅”。检查来源版本、文件名、预览与警告，再点击“导出已审阅快照”。批量预览展示当前任务的首份成品，结果表列出全部输出；成册预览展示完整手册。

项目 PDF 使用 Pandoc 和实际 PDF 引擎，不打开系统打印对话框，不将“打开打印”记作成功文件。HTML、DOCX、ODT、EPUB 可按依赖能力选择；一种格式失败不会把其他已生成文件标记为失败。

## 快照、结果与重试

冻结时，打开且未保存的有路径文档使用编辑器正文，其余文件从磁盘读取；未命名文档使用所选标签的正文。所有来源先形成有界清单，再逐章渲染。后续写出只使用已冻结的正文、主题、格式和 HTML，不在写出中混入新文档版本。

编辑所选缓冲区、改变顺序或输出设置会使审阅结果过期，必须重新冻结。切换无关标签不会扩大选择范围。磁盘上的外部修改由下次版本校验识别。

每项结果独立保留。批量中某篇不可读或渲染失败会明确列为失败，其他可用来源可以继续；合并成册必须具备所有选中章节，缺章时阻止成册，避免默默发布不完整手册。

“校验版本并重试失败项”先重新核对整个来源清单，包括当前脏缓冲区及未命名标签；正文版本改变则要求重新准备。重试保留成功项，不重复写出。写出/依赖检查失败可重新预检；此前没有成功渲染的章节恢复后，以及重试出现新警告时，任务停在就绪状态，必须重新审阅后再导出。最初不可读、没有可冻结快照的来源，需要重新冻结任务。

取消会阻止尚未发起的项目并取消正在写出的后端任务。取消前已经提交的成品保留并显示成功；未执行项显示取消。准备快照期间取消后需要重新准备。关闭窗口也取消未完成工作，不在后台自动恢复任务。

## 文件名与已有成品

批量文件名支持 `{name}`、`{profile}`、`{date}`，并添加根据来源相对路径身份生成的稳定后缀。重名、大小写接近、Windows 保留名称和非法字符都会被处理；实际名称在开始前显示。合并成册使用指定的书名文件名和格式扩展名。

默认不覆盖已有输出。输出存在时保留原字节，将该项列为失败；需要替换时明确勾选“替换已有输出文件”，再重新冻结。后端以原子禁止覆盖方式发布文件，避免预检后另一个写入者创建文件时发生覆盖。取消或失败不应破坏旧成品。

输出目录使用选中项目预设的相对目录。更改目录后应先保存项目方案，使该目录成为项目配置中的输出目录，再执行任务；项目授权与路径校验继续由 Rust 执行。所有预设声明的输出目录都会从候选输入、笔记枚举和 Agent 项目检索中排除。

## 成册规则

每章先按其原来源位置完成图片资源处理，再合并准备好的 DOM；不通过直接拼接原始 Markdown 成册。相同名称的 `image.svg` 可分别来自不同章节目录，不能混用资源基准。

章节容器、标题、脚注、图表和 SVG/CSS 引用使用确定命名空间。重复脚注标签仍属于各自章节；重复标题、原生 HTML 标题、别名及跨章 Markdown/Wiki 链接按实际渲染目标映射。未纳入、缺失或有歧义的目标会给出问题提示，不随机选择同名文档。Markdown 标题的临时来源标记不会进入成品。

章节标题按指定层级插入，正文标题排在章节标题之下；超过六级时提示。目录按实际成册标题生成，并保留主题所需样式、公式字体和静态图表。批量输出中的已纳入笔记链接改为对应格式的成品文件名；PDF/办公阅读器对外部文件锚点的支持由阅读器决定。

预览中的目录、跨章及脚注锚点在当前正文内滚动。预览不打开外部网页或其他文件，以免离开已审阅内容；实际导出成品仍保留对应链接。

远程图片和外部图表资源仍按 M1 策略处理：不自动联网下载，不能安全离线渲染的图表保留源码并提示。普通 Mermaid、内联 Vega、公式和项目内图片继续使用共享渲染及预检流程。

## 项目方案

方案保存在 `.markcaptain/export.json` 的可选 `projectExport` 字段，外层配置版本仍为 1，兼容已有 `profiles/defaultProfile`。示例：

```json
{
  "schemaVersion": 1,
  "defaultProfile": "technical",
  "profiles": ["此处为已有完整预设对象"],
  "projectExport": {
    "schemaVersion": 1,
    "mode": "book",
    "title": "项目手册",
    "chapters": [
      { "path": "intro.md", "title": "简介", "level": 1 },
      { "path": "guide/setup.md", "title": "配置", "level": 1 }
    ],
    "formats": ["html", "docx"],
    "profileId": "technical",
    "bookFileName": "handbook",
    "overwrite": false
  }
}
```

示例中的 profiles 占位需由应用已有完整预设替代，建议通过界面保存，不直接复制整个示例作为有效配置。

保存方案仅保存相对章节路径、顺序、标题、格式及设置，不自动开始导出，也不保存正文、未命名标签 ID 或权限。未知扩展字段保留；保存前比较 fingerprint，并按实际格式化 JSON 检查文件大小。无效配置和未知版本不会被默认值静默覆盖。

## 当前限额与范围

| 范围 | 限额 |
| --- | --- |
| 候选文档 | 5,000；超限明确报错，不返回似乎完整的截断列表 |
| 单次选择 | 64 篇 |
| 单篇冻结正文 | 2,000,000 UTF-8 bytes |
| 整体冻结正文 | 4 MiB，包含未命名文档 |
| 累计准备 HTML | 48 MiB |
| 配置 | `.markcaptain/export.json` 最终格式化字节最多 256 KiB |

候选和快照只允许当前窗口所属项目；不跟随符号链接或目录联接绕过项目范围。项目配置输出目录及构建/缓存目录不作为输入。

实际验证与未验收边界见 [M3 验证记录](M3_VALIDATION.md)。
