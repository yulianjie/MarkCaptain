# Agent 协作修改：主 Agent 评审记录

日期：2026-10-08。

三项意见均合理，适用于共同编辑逻辑。当前全文快照校验是必要保护，实施时保留最终应用校验，增加精确锚点和安全恢复审阅，而不直接放宽旧建议的应用条件。实施分工见 [计划](AGENT_COLLABORATION_PLAN.md)。

## 实施结果

| 意见 | 已完成范围 |
| --- | --- |
| 人与 Agent 同时编辑 | 即时过期提示、禁用失效操作、按当前授权重新生成、保守段落三方比较、新卡再次确认、冲突反馈与旧卡只读 |
| 外部 Agent 文档接口 | 默认关闭的单文档授权、打包 stdio MCP 适配脚本、实时未保存缓冲区/选区/版本、提案进入现有审阅、逐项结果查询与迁移追踪 |
| 重复文本精确定位 | 绑定每轮快照的绝对 UTF-16 锚点、读取/逐个搜索命中返回位置、前后端校验原文/范围/版本/代理对/重叠，兼容旧唯一原文匹配 |

## 主评审中补强的边界

- 生成新卡后原卡只读，防止撤销正文后重复应用旧建议。
- 同段任何变化、重复段删除及段落顺序歧义都保守报冲突；比较限制文档和段落数量，避免无界计算。
- 已接受相邻插入不会混入其他待审替换；已接受、拒绝和撤回决定不重新播放。
- 用户明确重新选择并附加当前段落后可恢复重新生成，禁止隐式全文回退。
- 多轮迁移采用有界祖先映射，外部结果和本地历史都保留原修改关系；旧反馈标记已迁移。
- 不同快照版本仍共享历史正文存储，避免每轮重复保存相同长文档。
- 外部请求使用本机随机端口和内存能力凭据，窗口所有权、生命周期、撤权竞态、单调版本、帧大小、并发、超时及 stdio 背压均受检查。
- 原生验收发现并修复 Windows 扩展路径不能作为 Node 启动入口的问题；脚本资源内容与源码一致。

## 首版限制

- 三方比较按整段保守对齐，不保证所有可人工合并的字符级修改都能自动重定位。超过预算或位置有歧义时需重新生成。
- 外部接口授权整篇选定文档，选区为元数据；不是任意工作区接口。外部重新生成由客户端重新读取并提交，不能从编辑器自动驱动任意客户端。
- 内部附加范围仍约束手动重新审阅，过期的内部选区需重新附加或明确切换为全文。
- MCP 使用真实脚本和 Rust/WebView2 链路验收，未分别连接 Codex、Claude 客户端或真实云模型。
- 当前机器是 Windows，未进行 Linux/macOS 桌面实机和安装器验收。
