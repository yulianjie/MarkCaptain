## 架构复核

- Rust 新增操作复用已打开项目的 canonical 根目录授权。扫描在阻塞工作线程执行、读取有大小限制、创建使用 `create_new`，避免截断现有每日笔记。
- 解析、关系查询、结构化搜索及引用规划使用 Web Worker。一次共享解析规则处理代码排除、链接、标签、属性与真实任务；解析及关系任务可以取消，索引取消后可完整重建。
- 文档状态仍由 `editor.tabs` 唯一持有。区域适配器隔离光标和源码编辑状态；活动区域选择写回当前视图，Agent 继续使用原有快照及审阅合同。Muya 渲染改为所属容器，避免多个区域共用全局节点。
- 本地历史保存在应用数据目录，独立于 Agent、草稿与远端历史。正文 SHA-256 去重，元数据与正文分开加载；恢复当前文档必须成功保存恢复前快照。历史错误提示后允许正常文件保存继续；恢复为新文档标记为未保存。
- 引用事务先验证全部文件，再写原始字节备份，逐文件检查后原子替换。失败尝试回滚；后续修改会阻止自动恢复并保留备份。
- 属性更新只替换一个 YAML 值或添加一个字段；复杂、锚点与自定义类型留在源码中编辑。

## 原生验证与浏览器验证区分

浏览器 E2E 驱动真实 Vue、Pinia、Muya 和 CodeMirror，替换需要桌面或模型的传输边界。

Windows 原生验证使用复制的可执行文件、独立应用标识 `io.github.yulianjie.markcaptain.notebook-validation` 和独立 WebView2 数据目录，未使用安装版的写入配置。项目测试文件均在忽略的 `output/notebook-native` 内。原生 IPC 和 Rust 文件操作没有模拟。

验证脚本与本地结果：

- `scripts/notebook-native-smoke.mjs`：中文路径、同名及别名、每日笔记不覆盖、历史恢复前保护与撤销、引用事务的 BOM／CRLF／文字／锚点及回滚、外部增删、分屏编辑和外部修改冲突。结果：`output/notebook-native/receipt.json`，八条流程通过，无页面异常。
- `scripts/notebook-native-restart.mjs`：持久化未保存草稿，终止验证进程后重新启动，从恢复提示恢复草稿及双区域布局。结果：`restart-receipt.json`。
- `scripts/notebook-native-agent.mjs`：真实 Rust HTTP／工具循环、当前附加文档读取、原生可视化分屏审阅、应用、Ctrl+Z、继续对话，收到 `reverted` 反馈。仅模型响应由本机临时服务提供。结果：`agent-receipt.json`。
- `scripts/notebook-production-smoke.mjs`：实际优化版、`tauri.localhost` 自定义协议和生产 CSP 下加载索引／关系 Worker，验证别名打开、每日笔记、历史、共享编辑／撤销及恢复内容的脏状态。结果：`production-receipt.json`，四条流程通过，无页面异常。

以上结果和截图是本机验证产物，不提交到 Git。
