## 1. 产品目标与最终推荐

MarkCaptain 以本地 Markdown 文档为中心，提供可靠的可视化编辑、写作时可见的双链、可审阅的文档 Agent，以及主题化、可复用的项目导出。

共同验收流程：

> 打开本地文档 → 侧边查看关联资料 → Agent 引用授权资料提出修改 → 用户逐项审阅 → 使用项目主题预览和导出。

推荐按依赖交付：

| 阶段 | 重点 | 交付结果 |
| --- | --- | --- |
| M0 | 建立基线与协议 | 编辑、分屏、Agent、导出样例及失败清单，明确文档身份和配置模型 |
| M1 | 核心体验 | 常驻双链、可见上下文、细粒度审阅、统一导出、三套主题、项目预设 |
| M2 | Agent 深化 | 本地项目检索、写作规范、文档检查、可选审阅恢复、可选联网研究 |
| M3 | 项目交付 | 批量导出、合并成册，随后加入明确范围的多文档修订 |

M1 是首个完整交付包。M2、M3 按功能继续交付，不合成一次大型改版，不预先承诺版本号或工期。

### 1.1 必须保留的产品原则

- Markdown 与附件是内容主体；单独打开一篇文档不强制创建项目。
- 编辑、保存、恢复、索引和基础导出支持离线；AI 是否联网取决于所选模型和资料来源。
- 索引是可重建的辅助数据，不建立替代文件系统的专有笔记对象。
- 任务内已授权的只读调用可连续执行，不为每次读取反复弹窗。
- AI 继续先提出修改，再由用户审阅应用。扩大资料检索范围，不自动扩大编辑范围。
- 导出不改写或自动保存源文件，不改变编辑主题。
- 密钥和认证头继续保存在系统凭据库，不进入项目配置、模型上下文或日志。
- 保留源码模式、快捷键、共享撤销、分屏、崩溃恢复和现有外部 Agent 边界。

完整数据库视图、Canvas、图谱、实时多人协作、通用插件市场和完整移动客户端，不属于本方案的交付前提。

## 3. 本地编辑与侧边双链

### 3.1 推荐布局

~~~text
┌──────────────┬────────────────────────┬──────────────────┐
│ 左侧导航     │ 正文编辑区             │ 右侧检查器       │
│ 文件树/搜索  │ 标签页                 │ 大纲 / 双链 / AI │
│              │ 可视化/源码            │                  │
│              │ 支持分屏               │ 可固定双链区域   │
└──────────────┴────────────────────────┴──────────────────┘
~~~

- 左侧用于定位文件，右侧用于理解和处理当前文档。
- 右侧默认标签切换，允许固定一个双链区域，与下方 Agent 上下并存。
- 首版不做任意拖拽停靠框架；支持显示、关闭、宽度拖动与键盘操作即可。
- 窄窗改为单辅助面板或抽屉，优先保证正文空间；阈值依据实际窗口、缩放与字体验证。
- 布局和固定状态属于个人偏好，不写入共享导出配置。
- 右侧默认跟随活动分屏，但运行中的 Agent 任务保持原来的目标身份。

### 3.2 双链检查器

面板包含：

1. 当前目标文档名、相对路径、“跟随活动文档/固定此文档”。
2. 反向链接、当前文档链接、未链接提及的独立计数和折叠。
3. 按来源文件分组的结果、匹配数量和可展开上下文。
4. 筛选、当前区域定位、在另一分屏打开。
5. 跳转后的返回操作，恢复发起区域、文档和光标。

状态分别显示：未打开项目、目标无路径、尚未索引、索引中、部分索引失败、确实没有关系。索引失败不能伪装成零结果。

已有路径的脏文档继续使用缓冲区覆盖磁盘分析；未命名文档仍能编辑和使用 Agent，但不虚构项目双链身份。首版关系范围为当前项目，不默认跨磁盘扫描。

首版未链接提及支持定位和参考。“一键建立链接”作为后续小项，通过正常编辑与撤销操作完成，不从 worker 直接写盘。

### 3.3 编辑重点

| 项目 | 实施内容 | 必须保留 |
| --- | --- | --- |
| 中文与选区 | IME、中文标点、混合字符、Emoji/UTF-16、粘贴 | 组合输入中不意外触发快捷操作或 Agent |
| 长文 | 大纲折叠、定位、章节整体移动 | 重排为一次可撤销操作，正文、列表与资源引用完整 |
| 表格 | Excel/TSV 粘贴、行列增删和移动、长内容 | 正确处理分隔符、换行及非规则粘贴 |
| 图片 | 粘贴、相对路径、缩放、缺失定位 | 编辑与导出共用源文档资源基准 |
| 分屏 | 同文件共享内容，各区域独立选区和模式 | 不另建脏状态、保存队列或撤销历史 |
| 恢复 | 外部修改、崩溃草稿、本地历史 | 文档恢复后重新校验 Agent 目标 |

复用现有 Muya 与 CodeMirror，不以更换编辑引擎为前提。

## 4. AI Agent：调研依据与实施设计

### 4.1 一手资料与痛点

2026-10-16 的子 Agent 调研覆盖 Obsidian Copilot、Smart Connections、Zed、Notion；2026-10-22 复查部分官方页面、公开问题和格式文档。资料用于设计依据，不代替竞品安装版完整测试。

| 一手资料 | 能力或案例 | 转化为设计要求 |
| --- | --- | --- |
| [Copilot Agent Chat](https://docs.obsidiancopilot.com/agent-mode-and-tools/) | 项目上下文、工具和技能、有权限的文件操作 | 上下文和执行过程可见 |
| [Copilot 检索](https://github.com/logancyang/obsidian-copilot/blob/master/docs/vault-search-and-indexing.md) | 文件、Obsidian 索引和语义检索各有路径 | 分清检索为空、索引未就绪和读取失败 |
| [Smart Environment](https://smartconnections.app/smart-environment/settings/) | 本地索引、范围与排除配置 | 本地范围可控，语义检索后续可选 |
| [Zed Agent](https://zed.dev/docs/ai/agent-panel) | 工具、差异与检查点 | 借鉴变更导航和恢复 |
| [Notion Agent](https://www.notion.com/help/notion-agent) | 工作区检索、多步骤页面任务 | 连接找资料、组织和修订 |
| [Copilot #2986](https://github.com/logancyang/obsidian-copilot/issues/2986) | 正文 raw diff、链接目标与 CJK 审阅问题 | 正文预览、中文细粒度差异、链接地址可见 |
| [Zed #47528](https://github.com/zed-industries/zed/issues/47528) | 重启后待审修改状态问题 | 关闭应用不能自动接受建议 |

公开 issue 是有版本和时间背景的案例，不能外推为普遍故障。Copilot #2986 迁入内部路线图，关闭状态不能证明已修复；本方案将案例转为回归用例。

### 4.2 面板与统一入口

输入区展示：

- 编辑目标：当前文档、指定选区或锁定的任务目标。
- 上下文：附加文档、任务检索范围、实际读取的片段。
- 模型：服务商、模型与资料实际去向。
- 来源：仅已附加资料、本地项目检索、结合网络。

“仅本地资料”描述来源，不等于模型离线；使用远程模型时，实际读取的片段仍发送到该模型，界面准确说明。

选区菜单、右键、命令面板、快捷键和聊天复用同一个请求流程：

~~~text
发起操作 → 固定文档/区域/选区与版本 → 整理授权上下文
        → 工具循环 → 回答或待审建议 → 应用与撤销同步
~~~

首批命令：润色、精简、续写、翻译、解释、检查术语、检查结构。保留自然语言输入，不强迫用户先学习命令。

### 4.3 细粒度审阅

- 稳定 change ID 连接聊天卡片、正文预览、历史与反馈。
- 待审正文使用只读覆盖层，不进入内容、脏状态、保存和导出。
- 正文按词语/短语突出变化，中文与日文适当分段，可退回字符级。
- 链接同时展示标签和目标 URL/路径变化。
- 表格提供单元格辅助视图、代码按行、Frontmatter 按字段；始终能查看原始 Markdown。
- 辅助视图只用于阅读，应用仍使用既有快照、原文、锚点、范围和重叠校验。
- 支持逐项接受、拒绝、定位、撤回，以及拒绝原因和按意见重写。
- 外围编辑复用安全 rebase；目标区域变化则转为冲突，不模糊定位强行应用。
- 全部接受只应用仍有效的项，单列冲突和未处理结果。

建议将持久化语义拆成三个维度：

| 维度 | 示例 | 含义 |
| --- | --- | --- |
| 用户决定 | undecided / accepted / rejected | 用户意图 |
| 文档效果 | notApplied / applied / undone / reverted | 修改是否仍在当前文档 |
| 校验状态 | valid / stale / conflicted / unavailable | 当前是否可安全操作 |

以上是目标语义，不直接替换现有枚举；实施时提供适配和迁移，保留撤销同步。

### 4.4 任务身份与失败处理

任务至少关联 taskId、paneId、documentId、snapshotId、选区、上下文版本和权限。切换分屏或面板不改变已发起任务的编辑目标。

阶段：queued → reading/searching → generating → awaitingReview → completed；另有 cancelled、failed、interrupted。部分审阅记录已接受、拒绝、冲突和未处理数量。

- 取消阻止后续调用，迟到结果按 taskId 丢弃。
- 网络失败保留阶段结果；重试重新校验，不再次应用已接受项。
- 相同版本下重复相同无效调用时停止循环并解释缺少的信息。
- 继承现有时间、工具和载荷限额，通过测量调整，不简单去掉上限。
- 文档切换、重启、重试不得造成重复执行。
- 任务结果保留已完成部分；导出和写文件成功不能由模型自行宣称。

### 4.5 本地项目检索

第一版复用文件名、标题、正文、标签、属性和关系索引，不要求下载 embedding 服务。

1. 用户启用目录范围和排除项。
2. 返回 documentId、路径、标题、片段、位置和索引状态。
3. 模型通过 documentId 按需读取，不能提供任意绝对路径。
4. 后端重新检查根目录与身份；脏文档以缓冲区为准，读取形成本轮只读快照。
5. 引用绑定快照和位置；界面区分“检索到”和“实际读取”。

建议新增模型工具 search_project(query, filters) 与 read_project_document(documentId, startLine, endLine)，沿用 cite_document。工具名与 typed IPC 是两层接口；候选结果不自动构成读取权限。

排除输出、缓存、构建目录和用户排除项；权限变更后旧候选失效。索引失败时可提供限范围字面搜索，并说明结果完整性。参考文档保持只读。

### 4.6 项目规范与检查

新增 .markcaptain/agent.json，保存写作要求与检索默认范围，不保存会话联网授权、密钥或机器程序路径。

~~~json
{
  "schemaVersion": 1,
  "writing": {
    "language": "zh-CN",
    "audience": "已有基础的产品使用者",
    "tone": "清楚、简洁、准确",
    "glossary": [
      { "preferred": "MarkCaptain", "avoid": ["Mark Captain"] }
    ]
  },
  "projectSearch": {
    "enabledByDefault": false,
    "include": ["**/*.md"],
    "exclude": ["exports/**", "node_modules/**", ".git/**", ".markcaptain/cache/**"]
  }
}
~~~

M2 已实现上述 schemaVersion 1 配置。打开陌生项目时，配置字段不能自行授予文件访问；当前授权只保留在窗口/会话内，不从项目配置或历史恢复。用法和实现边界见 [M2 工作流](M2_WORKFLOWS.md)。

检查分两类：

- 确定性检查：链接、资源、已声明术语、格式，提供可验证结果。
- 模型检查：矛盾、冗余、结构、解释不足，标为疑点或建议并附原文依据。

先给问题、位置、理由与依据，再生成修订；未进行外部核验的结论不能标为“已查证”。

### 4.7 可选联网研究

联网默认关闭，按任务启用后正常检索不重复弹窗。

1. 用户选择结合网络，并决定是否允许根据当前文档形成搜索词。
2. 可查看、调整查询；未选择文档生成查询时，仅使用用户输入的研究主题。
3. search_web 返回本轮 sourceId；open_web_source 按 sourceId 读取。
4. 用户直接提供的 URL 可注册为来源，经同一网络校验后读取。
5. 来源卡片展示标题、URL、获取时间、可用的发布日期与摘录，区分原文和推论。
6. 插入研究结果仍校验目标或通过补丁审阅。

实现边界：

- 不自动把全文、路径或认证信息混入查询，分别说明搜索服务和模型服务接收的数据。
- 网页与工具结果是资料，不能改变权限、读取任意文件或调用 Shell。
- 抓取限公网 HTTP/HTTPS；每次重定向和实际连接均校验目标，拒绝本机、内网和其他协议。
- HTTP 传输如实提示；模型端点采用独立策略，继续允许受信任 HTTP 配置。
- 设置来源数、体积、超时和重定向上限；默认不使用登录态、不执行网页脚本。
- 摘要、全文已读和抓取失败明确区分，不能伪造摘录。
- 默认仅保存引用元数据；网页正文缓存遵循本地历史设置，不自动创建整页笔记。

### 4.8 可选审阅恢复

复用现有可选 Agent 历史。关闭历史时不另存补丁全文。

开启后保存任务、快照引用、补丁、用户决定和状态，快照去重并继承限额、删除和导出功能；不保存密钥、认证头或图片载荷。

恢复时重新关联和验证。无法验证的记录仅供历史查看，操作禁用并解释；关闭或重启不得把 undecided 改成 accepted。

## 5. 导出：主题、预览与项目预设

### 5.1 统一导出流程

~~~text
菜单 / 命令 / 导出按钮
  → 固定内容快照
  → 解析默认值、项目预设与本次覆盖
  → 资源、链接、引擎和字体预检
  → 构建统一导出文档
  → HTML/打印 或 Pandoc 格式适配
  → 预览、生成临时产物
  → 提交输出或交给系统打印
~~~

默认使用发起时的缓冲区，包含未保存修改，不自动保存源文件。独立文件使用个人默认和用户选定位置。

编辑器可继续写作；预览注明内容时间，变化后标记过期并可刷新。同次预览与生成使用同一内容、主题、配置和资源快照，依赖变化后重做预检。

### 5.2 导出主题与格式能力

首批三套主题：

| 主题 | 用途 | 特点 |
| --- | --- | --- |
| 简洁阅读 | 文章与阅读分享 | 适中行宽、柔和层级、少装饰 |
| 技术文档 | 教程与技术方案 | 代码、表格清楚，标题层级与可选编号 |
| 正式报告 | 对外交付 | 标题页、目录、页边距、受引擎支持的页眉页脚 |

编辑与导出主题独立。默认浅色导出；“跟随编辑器”只对有明确映射的主题开放，不复制任意编辑器 CSS。

主题 token 包括字体、字号、行高、行宽、色彩、标题间距、表格、代码和打印页边距。暗色阅读可后续增加，打印默认浅色。

| 格式 | 样式机制 | 预览限制 |
| --- | --- | --- |
| HTML | CSS 与静态资源 | 同渲染器预览，字体和目标浏览器仍影响细节 |
| 系统打印/PDF | 独立导出视图与 print CSS | 最终分页、另存路径由系统决定 |
| Pandoc PDF | 明确引擎与对应模板参数 | 精确预览使用实际生成 PDF |
| DOCX/ODT | reference document 与格式适配 | 不承诺 CSS 像素复制 |
| EPUB | EPUB CSS 与资源 | 阅读器可能覆盖字体和布局 |

Pandoc 的 CSS、reference-doc、resource-path 和 PDF 引擎是不同能力，参考[官方手册](https://pandoc.org/MANUAL.html)。不支持的选项禁用或说明，不能静默忽略。

首版不要求内置 Chromium 或新 PDF 引擎。系统打印保留；Pandoc 依赖检测失败后提供安装说明或显式切换，不能报告生成成功。后续通过跨平台样例决定是否内置直接 PDF 引擎。

### 5.3 导出窗口

- 顶部选择目标、来源和格式。
- 左侧设置预设、主题、排版、资源和格式选项。
- 中部预览，支持缩放、目录导航、刷新与过期状态。
- 底部显示预检问题、依赖、输出、进度与结果。
- 明确区分仅本次使用、保存为项目预设、导出。
- 系统打印按钮标为“打开打印对话框”，不把此事件当文件已保存。
- 配置与渲染可取消，不阻塞编辑；新旧预览按版本区分。

### 5.4 独立只读导出视图

HTML/打印采用独立 WebView 或等效隔离视图，仅接收任务数据。不包含侧栏、工具栏、选区、输入控件、光标、Agent 覆盖层或业务事件。

复用 Markdown 解析并补齐导出扩展，不依赖克隆当前 Muya DOM；源码模式、非活动分屏和独立文件必须一致。

渲染就绪条件：字体加载、图片解码、公式与图表完成、目录和锚点生成。失败返回元素与原因，超时有明确结果。

Mermaid、Vega 等生成静态 SVG；格式不支持时转为 PNG 等替代并说明。渲染失败不能变成无提示的空白。

### 5.5 预检与显示优化

| 类型 | 处理 |
| --- | --- |
| 中文字体 | 检测实际字体，缺失时提示明确回退，不保证跨系统字形相同 |
| 图片 | 按源文档目录解析、检测缺失、限制尺寸、保留比例与替代文本 |
| 表格 | HTML 可横向阅读；打印合理拆页、重复表头；超宽提示横向或缩放 |
| 代码 | 稳定行高与缩进；打印可换行，长块允许拆页 |
| 标题 | 尽量和后续正文同页；编号和层级不改源文件 |
| 链接 | 转换 Wiki、标题锚点和脚注；缺失目标可定位 |
| 公式/图表 | 使用同一静态中间产物，等待完成后输出 |
| 打印装饰 | 按引擎支持启用封面、目录、页码、页眉页脚 |
| 隐私 | 不导出绝对路径、应用状态、Agent 隐藏上下文与认证信息 |

阻塞项包括目标不可写、资源未授权、所选引擎缺失、渲染失败；断链和非必要字体回退可明确选择继续，记录未解决问题。

不能对所有表格和代码强制“整块不分页”：超过单页高度时应按内容类型拆分，避免溢出和空白。

### 5.6 资源与写入

- HTML 支持单文件嵌入、文档加资源目录；仅内嵌 CSS 不算自包含。
- 每份原文保留资源基准。未命名文档无基准时显式选择，不猜测工作目录。
- 项目内资源可读取；项目外本地附件由用户明确选择授权。
- 远程图片默认不下载，离线打包下载需用户启用并使用网络校验，不附带认证信息。
- 按内容哈希去重、生成安全资源名，不在成品泄漏本机路径。
- 首版不运行自定义 JS、Pandoc filter 或项目脚本；样式和模板作为数据处理。
- 临时产物成功后提交目标；文件夹输出用暂存、受控替换和失败清理，保留旧成品。
- 配置与内容变化不会造成预览来源和最终输出来源不一致。

### 5.7 项目级导出配置

新增 .markcaptain/export.json，版本化 schema、界面与 Rust 校验、原子写入。目标示例：

~~~json
{
  "schemaVersion": 1,
  "defaultProfile": "technical",
  "profiles": [
    {
      "id": "technical",
      "name": "技术文档",
      "theme": "technical",
      "content": { "mode": "current", "source": "buffer" },
      "formats": ["html", "pdf", "docx"],
      "output": { "directory": "exports", "fileName": "{name}" },
      "typography": {
        "bodyFont": "system-cjk",
        "codeFont": "system-monospace",
        "bodySizePt": 11,
        "lineHeight": 1.65
      },
      "page": {
        "size": "A4",
        "orientation": "portrait",
        "marginMm": { "top": 20, "right": 18, "bottom": 20, "left": 18 }
      },
      "toc": { "enabled": true, "depth": 3 },
      "numberHeadings": false,
      "resources": { "htmlMode": "embed", "downloadRemote": false },
      "html": { "showTitle": true },
      "pdf": { "backend": "system-print" },
      "docx": { "stylePreset": "technical" },
      "epub": { "stylePreset": "technical" }
    }
  ]
}
~~~

以上为建议 schema，当前未实现：

- formats 是可选目标。system-print 不能作为无人值守 PDF 批量任务。
- output 配置只作用于应用直接生成的文件；系统打印使用系统路径和名称。
- stylePreset 指随产品提供并验证的样式；后续允许项目内 reference.docx/reference.odt。
- 字体别名在平台上解析，预检显示实际字体，不代表已经嵌入字体。
- 文件名变量使用白名单 name、profile、date，清理非法字符及分隔符。
- 共享配置使用项目相对路径；Pandoc 与引擎的机器路径保存在个人设置。
- 专用设置只在对应格式下生效，其他格式说明不支持。

优先级：内置默认 → 个人默认 → 项目预设 → 本次临时调整。对象按字段合并、数组整体替换；显示有效值来源，支持恢复继承。

无效配置不能覆盖原文；未知 schemaVersion 只读提示，已知版本迁移备份，保留未知扩展字段。外部修改时写入前比对版本/哈希并要求重新加载，不静默覆盖。

所有预设声明的项目输出目录均排除在索引、Agent 搜索及批量输入中，不只排除固定 exports 目录。

## 6. M3：多文件导出与多文档 Agent

### 6.1 批量与合并分开交付

| 模式 | 目标 | 关键处理 |
| --- | --- | --- |
| 批量 | 每份源文档生成成品 | 名称冲突、资源、逐项进度、失败与取消 |
| 合并 | 多份文档组成手册 | 显式顺序、层级、重复锚点、跨章链接、脚注与目录 |

章节使用显式清单；glob 用于候选选择，不按不稳定的遍历顺序成册。

按原文 sourceId 和资源基准解析后合并中间结构，不简单拼接字符串。标题、脚注、图表 ID 使用确定命名空间，跨章链接映射到新锚点；未纳入目标给出预检问题。

打开的脏文档用缓冲区，其他文件用磁盘，构建整体快照清单。未命名文档可加入本次任务，不保存成无法重建的章节路径。

批量保留逐项结果，重试校验版本；打开打印对话框不计文件成功。

### 6.2 多文档修订

用户显式选择可编辑文档集合后，按文件提交和审阅；项目可检索范围不等于可编辑范围。

首版按文件应用、每文件独立撤销和保护快照。“全部应用”要么预校验并提供恢复日志，要么明确可部分成功及逐项结果，不声称跨文件全局撤销。

默认不加入删除、改名、任意创建文件或 Git 提交工具。

2026-10-23 实施范围：1–8 个显式选择的打开文档，每份最多 2 MB、合计 4 MB；任务元数据先发、正文按需读取，逐文件应用/忽略/撤回和独立撤销。应用只改缓冲区，所选标签暂停自动保存；已有路径校验规范化内容与原始字节哈希，并在异步边界检查标签/路径/窗格身份。原文副本仅保留当前会话，不进入普通 Agent 历史，不承诺跨重启恢复。使用方法见 [A07 工作流](A07_WORKFLOWS.md)。

## 9. 验收细节

### 9.1 编辑与双链

- 文件树与双链并存，打开检查器不改变活动文档。
- 同名文件、别名、中文路径、重复标题准确区分。
- 外部改动、移动、删除、取消索引后关系更新或明确提示。
- 同文档双分屏编辑、源码切换、撤销不丢内容，不串 Agent 目标。
- IME、剪贴板表格、图片、长代码、公式和图表做真实桌面验证。
- 无项目单文件仍可编辑、使用 Agent 和导出，双链解释项目范围。

### 9.2 Agent

- 选区任务不读未授权项目；参考资料不隐式成为编辑目标。
- 外围手改可安全 rebase，区域内部变化报告冲突。
- 中文小改不显示无关整段替换，链接目标变化可见。
- 应用 → Ctrl+Z → 继续对话，以及重做、撤回、部分接受、按拒绝意见重写。
- 分屏切换、取消、重试、迟到结果不重复应用。
- 历史开/关、崩溃、重启、路径移动不会暗中接受建议。
- 越界目录、符号链接、错误 documentId 和失效 sourceId 后端拒绝。
- 网络摘要、全文已读、失败和来源日期明确区分。
- 本地模型离线验证与真实商业模型测试分别记录。

### 9.3 导出

- 三套主题逐一验证 HTML、打印及实际支持的 Pandoc 格式。
- 200 行代码、跨页长表、超宽表、多级标题、脚注、公式、Mermaid 和图片可读。
- 字体缺失、相对图片、项目外授权图片、断链、远程资源离线失败结果明确。
- 缓冲区、源码模式、非活动 Muya 不影响导出目标。
- 覆盖优先级、配置冲突、未知版本、迁移可复现。
- 输出存在、无权限、磁盘失败、缺引擎和取消不破坏旧成品。
- 断网打开自包含 HTML，打包资源范围内无需联网。
- 系统打印只声明打开对话框；自动生成验证文件存在、可打开、内容正确。
- M3 覆盖重复文件名/锚点、跨章资源/链接/脚注与部分失败。

### 9.4 性能和平台

记录硬件、系统、构建模式、字体、模型、Pandoc 和引擎版本。建议夹具：20 万字长文、1 MiB Markdown、1200/10000 文件项目，以及图表和大表格集合；遵守现有总量限额。

候选工程目标：常规输入 P95 延迟 50 ms，适用样例和硬件通过 M0 实测后锁定；打开、索引、预览记录冷/热启动和取消延迟。未测量前不承诺固定速度。

Windows WebView2 做真实原生验证；macOS/Linux 分别记录字体、打印和窗口差异。浏览器 E2E 不替代原生应用和安装器验收。
