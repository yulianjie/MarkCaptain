# MarkCaptain 写作工作台界面

2026-11-02：根据已确认的「安静的写作工作台」设计统一应用界面。设计稿中的阅读进度改为大纲面板的底部区域；真实应用的大纲列表独立滚动，进度区不随目录滚走。

## 界面范围

- 主工作区：工作区头部、文件/搜索导航、开始页、文档标签、路径、格式工具开关、画布、大纲与检查器、状态栏。
- Agent：上下文与工具/权限抽屉、模型信息、会话、逐项修改审阅、来源、历史、技能、设置、MCP 与多文档审阅。
- 偏好设置：保留十个分类和原有设置，新增主题卡片、分组说明与窄窗口布局。
- 导出：单文档、批量与成书的分组设置、真实预览、诊断、固定底部操作区。
- 笔记：双链、标签、属性、搜索、任务、模板、历史恢复、布局和多编辑窗格。
- 辅助窗口：命令面板、上下文菜单、最近文件、重命名、表格、图片、云存储、更新与关于。

开始页使用真实最近文件与现有新建/打开操作，不包含设计稿的示例笔记。切换开始页不销毁编辑器实例或未保存草稿；键盘重新激活当前文档、查找和编辑命令也会返回文档。

后续界面复核已移除侧栏重复的“打开的文件”区域，工作区目录直接占用导航空间。打开的文档仍通过页签、快捷键和菜单管理。多页签溢出时提供左右滚动入口，当前页签自动进入视野；每个页签保留不收缩的关闭按钮，边缘部分可见页签的关闭按钮不会再被裁掉。

## 主题与布局

`src/assets/styles/global.css` 提供默认暖白/鼠尾草绿和石墨深色。其他内置主题、用户主题、自动跟随系统和用户正文排版偏好均保留。

`src/assets/styles/workbench.css` 定义统一的界面字体、分层背景、状态颜色、边框、间距、圆角和 Element Plus 主题映射。控件变量使用高于 Element Plus 懒加载样式的根选择器优先级，避免菜单或表单重新变为默认蓝色。Muya 与 Mermaid 的全局测量盒模型不做重置。

主窗口在 1180px 及以下将检查器显示为抽屉，在 900px 及以下将文件导航收为活动栏。抽屉保持正文宽度，支持关闭、键盘焦点管理及焦点恢复。窗口缩小时仅限制实际可视宽度；主动拖动或键盘调整才更新持久化宽度。

设置页和复杂导出窗口采用局部滚动，底部操作保持可达。长表格保留局部横向滚动，不撑开整个窗口。

设置正文从导航右侧起排，嵌入 Agent 的标题区压缩为 40px。仍保留用户自定义侧栏和正文宽度，以及主窗口原有菜单；这些是功能保留，不把示例设计稿当作强制窗口尺寸。

原生标题栏通过 `cmd_window_set_theme` 跟随渲染器解析后的主题。浅色/深色明确设置原生窗口，系统模式清除覆盖；自定义主题根据实际背景判断亮暗。窗口首次显示前完成同步，设置窗口重新打开和跨窗口切换保持一致。偏好读取失败仍允许打开设置。

## 行为保持

保留原有文件格式与工作流 IPC。Agent 的修改提议、应用/拒绝/撤销、过期与冲突阻断、历史恢复锁定和外部访问授权继续使用原有逻辑。收起工具抽屉不会撤销现有授权。

导出仍由内容快照和预检驱动：设置变更使旧预览失效，错误阻断输出，警告需要确认。系统打印只打开打印对话框；Pandoc 文件生成与系统打印分别显示。预览不声称与 Pandoc 的最终分页一致。
