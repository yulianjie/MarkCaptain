# 人与 Agent 协作：审核与实施计划

日期：2026-10-08。适用于 Windows、Linux 和 macOS 的共同编辑逻辑。

## 审核结论

三项建议都合理。当前实现已经即时跟踪正文变化及编辑器撤销检查点，因此第一项并非从零增加过期检测；缺口是过期后的操作引导和安全恢复审阅。全文快照比较仍是最终应用的必要保护，不应直接放宽成一次字符串搜索。

重复原文的精确锚点应先实现，作为内置工具与外部接口的共同基础。外部 Agent 接口具有长期价值，首版只做用户主动授权的单文档审阅，不扩展到工作区访问。

## 修改顺序与边界

1. **锚点**：读取和搜索返回绑定不可变快照的 UTF-16 范围。提交时校验快照身份、原文、Unicode 边界、授权范围、重叠和大小限制。无锚点的旧调用继续要求唯一匹配。
2. **过期与重新审阅**：正文变化后立即显示过期，禁用旧补丁应用。用户可重新生成，或主动进行保守三方比较；仅把明确不冲突的待审修改转成新的差异卡，仍需再次确认。同段变更、重复段落歧义和无法可靠映射的范围报冲突。已接受或拒绝的修改不作为待审修改重新播放。
3. **外部接口**：默认关闭，用户授权当前文档后启动本机桥接。MCP 客户端可读取当前未保存缓冲区、选区和版本，提交建议、查询审阅结果。接口不提供任意路径、直接保存、直接应用或 Shell；授权撤销、文档关闭、窗口销毁和跨文档请求受保护。

## 验收

| 场景 | 预期 |
| --- | --- |
| 用户改开头，建议修改未变动的结尾 | 原建议过期；重新比较产生结尾的新待审差异；确认前不修改正文 |
| 用户修改建议所在段落 | 明确冲突，不定位到另一处相同文字 |
| 两个相同句子，只改第二个 | 锚点准确修改第二处；无锚点仍拒绝歧义 |
| 过期、越界、半个代理对、重叠锚点 | 前后端拒绝 |
| 外部 Agent 读取未保存正文 | 返回缓冲区而非磁盘旧内容，包含选区及版本 |
| 外部建议 | 进入现有审阅，接受/拒绝/撤回结果可查询 |
| 撤权、旧版本、跨文档或跨窗口 | 请求拒绝，不改正文或磁盘 |
| 源码与所见即所得应用及撤销 | 使用原编辑器事务机制 |

## 责任与验证

子 Agent 分别负责锚点、协作审阅、外部接口；主 Agent 评审契约一致性、权限边界、集成差异和验证结果。保留已有无关修改 `src-tauri/icons/icon.icns`，本轮不提交或发布。

验证包括针对性前后端测试、既有 Agent 回归、类型检查和构建。浏览器测试只证明前端流程；Windows 原生验证与 Linux 实机验证须分别记录，不能互相替代。
