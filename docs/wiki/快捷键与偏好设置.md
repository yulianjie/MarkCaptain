## 使用命令面板

`Ctrl/Cmd+Shift+P` 打开命令面板，按名称查找文件、编辑、段落、格式、视图、窗口、帮助和笔记操作。命令使用与菜单一致的动作入口；不可用时先确认是否打开文档、项目以及当前编辑模式。

## 常用默认快捷键

`Ctrl/Cmd` 表示 Windows/Linux 使用 Ctrl、macOS 使用 Cmd。下表来自当前快捷键注册表；系统、键盘布局和用户配置可能影响实际组合，以设置和菜单为准。

| 操作 | 默认快捷键 | 能否在快捷键设置重绑 |
| --- | --- | --- |
| 新建标签 | `Ctrl/Cmd+T` | 可 |
| 打开文件 | `Ctrl/Cmd+O` | 可 |
| 打开文件夹 | `Ctrl/Cmd+Shift+O` | 可 |
| 保存 / 另存为 | `Ctrl/Cmd+S` / `Ctrl/Cmd+Shift+S` | 可 |
| 关闭标签 | `Ctrl/Cmd+W` | 可 |
| 打印 | `Ctrl/Cmd+P` | 可 |
| 查找 / 替换 | `Ctrl/Cmd+F` / `Ctrl/Cmd+H` | 可 |
| 命令面板 | `Ctrl/Cmd+Shift+P` | 可 |
| 侧栏显隐 | `Ctrl/Cmd+Shift+B` | 可 |
| 快速打开笔记 | `Ctrl/Cmd+K` | 可 |
| 今日笔记 | `Ctrl/Cmd+Alt+D` | 可 |
| 插入模板 | `Ctrl/Cmd+Alt+T` | 可 |
| 偏好设置 | `Ctrl/Cmd+,` | 保留 |
| 新建窗口 | `Ctrl/Cmd+Shift+N` | 保留 |
| 关闭窗口 | `Ctrl/Cmd+Shift+W` | 保留 |
| 切换源码 | `Ctrl/Cmd+Alt+S` | 保留 |
| AI 助手 | `Ctrl/Cmd+Shift+A` | 保留 |
| 撤销 / 重做 | `Ctrl/Cmd+Z` / `Ctrl/Cmd+Shift+Z` | 编辑器保留；Windows/Linux 另支持 `Ctrl+Y` |
| 一级至六级标题 | `Ctrl/Cmd+1` 至 `Ctrl/Cmd+6` | 所见即所得模式保留 |
| 粗体 / 斜体 / 删除线 | `Ctrl/Cmd+B` / `Ctrl/Cmd+I` / `Ctrl/Cmd+D` | 所见即所得模式保留 |
| 插入链接 / 图片 | `Ctrl/Cmd+L` / `Ctrl/Cmd+Shift+I` | 所见即所得模式保留 |
| 放大 / 缩小 / 还原 | `Ctrl/Cmd+=` / `Ctrl/Cmd+-` / `Ctrl/Cmd+0` | 保留 |
| 全屏 | `F11` | 保留；依系统行为 |

分屏、命名布局、本地历史、笔记设置和引用事务恢复可直接从命令面板寻找，不需要为每项记住快捷键。

## 修改快捷键

在“偏好设置 → 快捷键”中找到可重绑动作，录制或修改组合键，检查冲突后保存；需要时恢复默认。不是每一项都开放自定义，原生、系统和编辑器保留键不能按普通应用动作修改。

修改后的配置由菜单、命令面板和对应应用动作共享。如果快捷键没有触发，检查焦点是否在对话框/输入框、命令是否适用于当前模式，以及是否与系统或其他动作冲突。

## 设置分类

| 分类 | 可调整内容 | 使用提示 |
| --- | --- | --- |
| 通用 | 自动更新、自动保存及延迟、启动行为、语言、标题栏、窗口尺寸记忆、应用图标、打开到新窗口、缩放、文件排序 | 自动保存默认关，更新检查默认开，启动默认空白页 |
| 编辑器 | 正文字体/字号/行距/行宽、代码字体与行号、自动配对、编码检测、默认编码、换行、文本方向 | 编码和换行影响落盘文件；状态栏展示当前文档值 |
| Markdown | 列表符号、缩进、标题风格、Frontmatter 类型、脚注、上下标、HTML 和兼容选项 | 脚注/上下标等扩展可能默认关闭 |
| 主题 | 内置/用户主题、自动深浅色切换 | 编辑主题不改变导出主题 |
| 图片 | 引用原路径、复制目录、相对图片目录、上传器配置 | 上传使用网络或本地外部程序 |
| 云存储 | Sync、Git、WebDAV、存储插件连接，测试与同步 | 本地保存状态与云端状态分别查看 |
| 拼写检查 | 开关、下划线、语言、可用词典 | 默认关闭；可选词典以当前系统检测结果为准 |
| 视图 | 侧栏、标签栏、工具栏、状态栏、默认源码模式等 | 专注和打字机模式也可从视图菜单切换 |
| 搜索 | 排除规则、大小、隐藏文件、忽略规则、符号链接 | 不等于笔记索引或 Agent 的授权设置 |
| 快捷键 | 查看、修改可重绑动作和恢复默认 | 保留动作只展示，不开放改写 |

Agent 服务、认证、技能与对话历史从 AI 助手内部管理。模板/每日笔记配置属于项目笔记设置，项目写作规范和导出预设分别属于各自工作流；不要把它们当成同一组全局偏好。

## 默认行为速查

| 设置 | 当前默认 |
| --- | --- |
| 自动保存 | 关闭；启用后延迟 5000 ms，已有路径才生效 |
| 自动更新检查 | 开启；启动后约 10 秒及运行中每 4 小时 |
| 启动行为 | 空白页，可改为上次状态或指定目录 |
| 记住窗口尺寸 | 关闭，可开启；窗口位置另行处理 |
| 图片插入 | 引用路径；相对图片目录名称为 `assets` |
| 拼写检查 | 关闭 |
| 默认编辑模式 | 所见即所得 |
| 自动猜测编码 | 开启 |
| Agent 对话历史 | 关闭，需在助手历史面板启用 |
| Agent 联网研究 / 外部 MCP | 关闭，分别显式授权 |

设置改变后建议立即用一个临时文档确认效果。外部工具路径、上传器和远端凭据的配置是否有效，需通过对应功能单独测试。
