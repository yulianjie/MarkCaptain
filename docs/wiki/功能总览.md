## 哪些功能需要网络或外部程序

| 使用方式 | 需要什么 |
| --- | --- |
| 编辑、笔记索引、结构化搜索、双链、本地历史、本地确定性检查 | 本地文件与桌面运行环境，不需要模型服务 |
| Agent 写作、模型检查、分章总结、多文档修订 | 支持相应协议的模型；远程服务需要网络，本地 Ollama 需要自行部署 |
| 图片问答 | 模型同时支持图片、流式输出和工具调用；文本连接测试不证明视觉能力 |
| 项目检索 | 本地项目加显式只读授权；实际读到的片段会进入配置模型的请求 |
| 联网研究 | 每轮启用并批准查询或 URL；公开网页可访问 |
| HTML、系统打印 | 无需 Pandoc；最终打印/保存由系统完成 |
| DOCX、ODT、EPUB | 本机 Pandoc |
| Pandoc PDF | 本机 Pandoc 和可用 PDF 引擎，当前探测 XeLaTeX、Typst、WeasyPrint |
| Git 同步 | Git 程序、已有仓库、remote/branch 及该环境的认证 |
| Sync、WebDAV、存储插件 | 对应服务或可信本地插件及凭据 |
| 外部 MCP | 本地客户端、Node.js 18+、当前文档的临时授权 |

## 使用范围

MarkCaptain 的主数据是本地 Markdown。编辑器的“已保存”表示本地写盘成功；远端同步有独立状态。项目索引、Agent 检索和导出各有自己的范围、排除规则与预算，某一处能看到文件不等于其他功能获得同样权限。

模型工具没有任意 Shell、Git 提交、删除、改名或直接保存能力。只读项目资料不会因检索而变成编辑目标。外部 MCP 只共享一个授权文档，不能继承内置 Agent 的项目/Web 权限。

当前不应承诺：无限项目索引、语义向量知识库、静默覆盖冲突、跨文件一键原子应用、跨重启重放多文档修订、自动下载全部远程资源、所有格式与预览逐像素相同，或所有模型和所有操作系统均已实机验收。
