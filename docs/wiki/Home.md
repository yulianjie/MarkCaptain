## 快速开始

1. 从 [Releases](https://github.com/yulianjie/MarkCaptain/releases/latest) 下载适合当前系统的安装包。
2. 启动 MarkCaptain，使用“文件 → 打开文件”编辑单个 Markdown 文件，或使用“文件 → 打开文件夹”管理一个项目。
3. 直接在所见即所得编辑器中写作；需要查看原始 Markdown 时切换源码模式。
4. 使用命令面板快速查找操作，使用“偏好设置 → 快捷键”查看或修改当前快捷键。
5. 如需写作 Agent，从标题栏、“视图”菜单或命令面板打开“AI 助手”，配置自己的模型服务后再发送内容。

## Quick start

1. Download the package for your platform from [Releases](https://github.com/yulianjie/MarkCaptain/releases/latest).
2. Open one Markdown file, or open a folder to work with a project tree.
3. Write in the WYSIWYG editor and switch to source mode whenever you need the raw Markdown.
4. Use the command palette to find actions and Preferences to inspect or customize shortcuts.
5. Open AI Assistant from the title bar, View menu, or command palette, then configure your own model provider before sending document context.

> MarkCaptain writes normal Markdown files. Keep important work in your usual backup or version-control workflow.
