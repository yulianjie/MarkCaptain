# MarkCaptain 使用指南

[首页](https://github.com/yulianjie/MarkCaptain/wiki/Home) · [功能总览](https://github.com/yulianjie/MarkCaptain/wiki/%E5%8A%9F%E8%83%BD%E6%80%BB%E8%A7%88) · [English](https://github.com/yulianjie/MarkCaptain/wiki/User-Guide)

本指南帮助你从安装走到第一次文档交付。完整功能按主题分布在 Wiki 导航；文档基线见[首页](https://github.com/yulianjie/MarkCaptain/wiki/Home)。

## 1. 安装与启动

从[项目 Releases](https://github.com/yulianjie/MarkCaptain/releases)选择版本和系统架构。发布工作流面向以下平台，实际可下载文件以该版本资产为准。

| 平台 | 软件包与选择 |
| --- | --- |
| Windows x64 | NSIS `.exe` 或 MSI 安装包 |
| Linux x64 | AppImage、DEB 或 RPM，按发行版选择 |
| macOS Apple Silicon | ARM64 `.app.tar.gz`；该版本提供 DMG 时也可使用 |
| macOS Intel | x64 `.app.tar.gz`；该版本提供 DMG 时也可使用 |

Windows 桌面程序使用 WebView2。无法启动时先核对 Runtime 和系统错误；macOS 按系统对独立分发应用的提示处理。更新包的 `.sig` 和 `latest.json` 是更新校验材料，无需当作应用安装。

启动后不需要先注册 MarkCaptain 账号即可编辑本地文档。模型服务、自建同步服务和其他远端服务可能各自需要凭据。可在偏好设置中选择简体中文、English 或日本語。

## 2. 创建第一篇文档

1. 使用“文件 → 新建”或 `Ctrl/Cmd+T` 建立未命名标签。
2. 输入标题、正文和列表；默认是所见即所得模式。
3. 按 `Ctrl/Cmd+S`，选择文件位置，例如 `Documents/Notes/入门.md`。
4. 观察底部保存状态。未命名文档必须先保存一次，才有自动保存目标。
5. 需要精确修改 Markdown 时，用“视图 → 源码模式”切换；两种模式编辑的是同一份正文。

自动保存默认关闭；开启后默认延迟为 5 秒。关闭标签或窗口时留意未保存提示。详细的外部修改处理、编码和崩溃恢复见[编辑与工作区](https://github.com/yulianjie/MarkCaptain/wiki/%E7%BC%96%E8%BE%91%E4%B8%8E%E5%B7%A5%E4%BD%9C%E5%8C%BA)。

## 3. 打开文件夹作为项目

使用“文件 → 打开文件夹”或 `Ctrl/Cmd+Shift+O` 选择一个本地目录。建议先用一个临时项目练习：

```text
我的笔记/
  入门.md
  项目计划.md
  assets/
  Daily/
  Templates/
```

文件树用于浏览和管理文件；笔记面板提供链接、标签、属性、结构化搜索和任务。右侧检查器提供大纲、双链及 AI 助手。打开项目不会自动把整个目录发送给模型。

按 `Ctrl/Cmd+K` 快速打开笔记，可以搜索名称、相对路径和 YAML 别名；无精确匹配时可创建新笔记。用 `[[项目计划]]` 建立内部链接，按住 `Ctrl/Cmd` 点击跳转。更多示例见[笔记与知识管理](https://github.com/yulianjie/MarkCaptain/wiki/%E7%AC%94%E8%AE%B0%E4%B8%8E%E7%9F%A5%E8%AF%86%E7%AE%A1%E7%90%86)。

## 4. 用命令面板寻找操作

按 `Ctrl/Cmd+Shift+P`，输入“分屏”“模板”“今日笔记”“本地历史”或操作名称，再选择执行。部分命令需要先打开文档、项目，或者处于所见即所得模式。

快捷键中 `Ctrl/Cmd` 表示 Windows/Linux 使用 Ctrl、macOS 使用 Cmd。只有部分动作可重新绑定；请以“偏好设置 → 快捷键”中当前配置为准。参见[快捷键与偏好设置](https://github.com/yulianjie/MarkCaptain/wiki/%E5%BF%AB%E6%8D%B7%E9%94%AE%E4%B8%8E%E5%81%8F%E5%A5%BD%E8%AE%BE%E7%BD%AE)。

## 5. 第一次使用写作 Agent

1. 从右侧检查器、标题栏、“视图”菜单或 `Ctrl/Cmd+Shift+A` 打开 AI 助手。
2. 在助手设置中选择 DeepSeek、OpenAI、自定义 OpenAI 兼容接口或本地 Ollama，填写基础地址、模型 ID 和认证方式。
3. 保存并测试连接；本地无认证服务可选择“不使用认证”。
4. 选中一段文字，确认面板中的附加范围，输入“在不改变事实的前提下精简这段文字”。
5. 发送后检查原文、修改后文本和引用，再决定应用或忽略。
6. 应用后检查编辑器，再按正常流程保存；启用了普通自动保存时，单文档缓冲区修改也可能随后保存。

只读问答、分章总结、参考文档、图片、技能和多文档修订的完整流程见[AI 写作助手](https://github.com/yulianjie/MarkCaptain/wiki/AI%E5%86%99%E4%BD%9C%E5%8A%A9%E6%89%8B)。多文档修订会暂停所选标签的自动保存，需手动保存。

## 6. 第一次导出

1. 使用“导出 HTML”、其他导出菜单或打印入口，进入统一导出窗口。
2. 选择格式、主题、纸张与排版参数，生成预览。
3. 检查图片、公式、图表和资源警告。预览采用发起时的正文，包含未保存修改。
4. 选择输出位置并导出；若文档或设置变化，先重新生成预览。
5. 使用系统打印时，在操作系统对话框中完成打印或保存 PDF。

HTML 与系统打印无需 Pandoc。DOCX、ODT、EPUB 以及直接生成 PDF 的 Pandoc 路径需要本机相应依赖。批量输出和成册见[导出与成册](https://github.com/yulianjie/MarkCaptain/wiki/%E5%AF%BC%E5%87%BA%E4%B8%8E%E6%88%90%E5%86%8C)。

## 7. 开始长期使用

- 把图片放在项目内相对目录，与 Markdown 一起备份或同步。
- 按需设置模板、每日笔记、命名布局和本地历史。
- 启用远端同步前，核对本地目录、远端目标和冲突策略。
- 授权项目检索与联网研究前，核对实际范围；这些权限不会因打开项目自动授予。
- 更新前保存文档；出现异常先看[常见问题](https://github.com/yulianjie/MarkCaptain/wiki/%E5%B8%B8%E8%A7%81%E9%97%AE%E9%A2%98)，反馈时附上版本、最短复现步骤和脱敏信息。
