# MarkCaptain 使用指南

[Wiki 首页](Home) · [English](User-Guide) · [下载](https://github.com/yulianjie/MarkCaptain/releases/latest) · [问题反馈](https://github.com/yulianjie/MarkCaptain/issues)

本指南适用于 [`yulianjie/MarkCaptain`](https://github.com/yulianjie/MarkCaptain) 发布的 Tauri 版 MarkCaptain。

## 1. 安装与启动

从 [GitHub Releases](https://github.com/yulianjie/MarkCaptain/releases/latest) 下载对应平台的软件包：

| 平台 | 软件包 |
| --- | --- |
| Windows x64 | NSIS `.exe` 或 MSI |
| Linux x64 | AppImage、DEB 或 RPM |
| macOS Apple Silicon | ARM64 `.app.tar.gz` |
| macOS Intel | x64 `.app.tar.gz` |

Windows 11 通常已包含 WebView2；Windows 10 如无法启动，需要安装 Microsoft WebView2 Runtime。macOS 独立分发版本可能需要按系统提示确认 Gatekeeper。

MarkCaptain 默认把文档保存在你选择的本地路径，不会要求登录账号。更新前请先保存所有打开的文档。

## 2. 打开文档与项目

- **新建文档**：创建一个未保存的 Markdown 标签页；首次保存时选择文件名和位置。
- **打开文件**：打开一个或多个 Markdown 文件。最近使用的文件可以从“最近使用”重新打开。
- **打开文件夹**：把文件夹作为项目打开，在侧栏浏览目录树、已打开文件、文章目录和搜索结果。
- **多标签页**：可同时编辑多个文档。关闭含未保存内容的标签页或窗口时，应用会要求你确认。
- **文件变化**：MarkCaptain 会监听磁盘文件变化；当外部程序修改当前文档时，按应用提示决定是否重新载入。

MarkCaptain 使用普通 Markdown 文件。项目目录可以继续由 Git、同步盘或你自己的备份工具管理。

## 3. 编辑 Markdown

默认编辑器是 Muya 所见即所得界面。标题、列表、表格、任务列表、代码块、引用、链接、图片、脚注、数学公式等内容会直接显示为排版结果。

- 使用“视图 → 源码模式”在所见即所得和原始 Markdown 之间切换。
- 使用“编辑 → 查找”或“编辑 → 替换”搜索当前文档。
- 使用侧栏的全局搜索查找项目内的 Markdown 内容。
- 使用文章目录快速跳转到当前文档的标题。
- 使用专注模式和打字机模式减少界面干扰。
- 使用工具栏、原生菜单、右键菜单或命令面板执行格式操作。

### 图表与代码

代码块支持语法高亮。图表内容支持 Mermaid、Flowchart、Sequence 和 PlantUML 等格式；请在对应的围栏代码块中使用正确语言标识。

### 图片

可通过选择文件、粘贴或拖放插入图片。实际行为取决于“偏好设置”中的图片策略：引用原路径、复制到指定文件夹，或使用已配置的上传器。移动文档或图片后，如果相对路径发生变化，请检查引用是否仍然有效。

## 4. 命令面板与快捷键

命令面板集中提供文件、编辑、段落、格式、视图、窗口和帮助操作。快捷键可以在“偏好设置 → 快捷键”中查看、录制、修改或恢复默认值。

快捷键使用统一注册表，原生菜单、命令面板和编辑器共享同一份配置。由于用户可以自定义按键，请以偏好设置中当前显示的组合键为准。

## 5. 导出与打印

- **HTML**：导出带样式的 HTML 文件。
- **打印 / 保存 PDF**：打开系统打印对话框；系统支持时可选择“保存为 PDF”。
- **Pandoc 导出**：安装 Pandoc 及目标格式需要的引擎后，可导出 PDF、DOCX、ODT 或 EPUB。

Pandoc 不随 MarkCaptain 打包。导出失败时，请先在终端确认系统能找到 `pandoc`，并检查 PDF 引擎、字体和图片路径。

## 6. 写作 Agent

从标题栏、“视图”菜单、命令面板打开“AI 助手”，或使用偏好设置中显示的快捷键。

### 配置模型

1. 打开 Agent 设置。
2. 选择 DeepSeek 预设、自定义 OpenAI 兼容接口或本地 Ollama。
3. 填写服务地址、模型 ID 和所需凭据。
4. 保存后发送一条短消息验证配置。

HTTP 地址可用于受信任的本地网络，但提示词和凭据不会获得传输加密；离开受控网络时优先使用 HTTPS。

### 使用方式

- Agent 只读取你明确附加的当前文档、选区、图片或只读 Markdown 参考资料。
- 可让它润色、续写、解释、比较、生成提纲或分段总结长文。
- 修改建议会先显示差异；应用、忽略、定位或撤回均由你决定。
- 回答可以插入光标、追加到文末、替换选区，或创建为新的未保存文档。
- 对话历史默认关闭；开启后保存在本地，API Key 和图片不会写入历史记录。

Agent 不能扫描整个文件系统、执行 Shell、提交 Git、联网搜索，也不能绕过审阅直接保存你的文档。完整安全边界见[写作 Agent 文档](https://github.com/yulianjie/MarkCaptain/blob/master/docs/AI_AGENT.md)。

## 7. 本地项目与远端存储

MarkCaptain 始终先保存本地工作副本。可选远端存储不会把一次成功的本地保存变成失败。

- **MarkCaptain Sync**：连接自建同步服务。
- **Git**：支持校验仓库、fetch、仅快进 pull 和非 force push；不会自动 reset、提交或强推。
- **WebDAV**：使用 ETag 保护条件写入；无法可靠判断远端版本时会拒绝不安全覆盖。
- **存储插件**：仅安装并信任你了解的本地原生插件。

发生离线、分叉或内容冲突时，先保留本地副本，再根据界面显示的本地/远端版本决定处理方式。

## 8. 偏好设置

偏好设置包括外观、编辑、图片、拼写检查、快捷键、Agent、应用图标和其他桌面行为。语言支持简体中文、English 和日本語；主题支持自动深浅色以及多套内置主题。

修改快捷键、图片目录或外部工具路径后，建议立即用一个临时文档验证。涉及凭据的 Agent 配置保存在操作系统凭据库，而不是普通偏好设置文件。

## 9. 更新、帮助与问题反馈

- “帮助 → 打开文档”会打开本项目 Wiki。
- “帮助 → 报告问题”会打开本项目 Issues。
- “帮助 → 检查更新”仅在发布版本配置了可验证的更新源时可用；也可以直接访问 [Releases](https://github.com/yulianjie/MarkCaptain/releases/latest)。

提交问题前请准备：

1. MarkCaptain 版本、操作系统和安装包类型；
2. 可稳定复现的最短步骤；
3. 预期结果和实际结果；
4. 不包含私人文档、API Key、认证头或其他秘密的截图与日志。

在 [GitHub Issues](https://github.com/yulianjie/MarkCaptain/issues) 中搜索是否已有相同问题，再创建新 Issue。

## 10. 常见问题

### Windows 上无法启动

确认已安装 WebView2 Runtime，并尝试使用最新发布版本。企业设备还可能受到应用执行策略限制。

### 图片在另一台设备上不显示

优先使用相对路径，并把图片目录与 Markdown 文件一起同步。绝对路径通常只在原设备有效。

### PDF 或文档导出失败

系统打印不依赖 Pandoc；Pandoc 导出则需要独立安装 Pandoc 及目标格式所需引擎。两条路径请分开排查。

### Agent 请求失败

检查服务地址、模型 ID、认证方式和网络可达性。本地 Ollama 通常不需要 API Key；远端兼容接口可能要求 Bearer Key 或自定义认证头。不要把凭据粘贴到 Issue。

### 文件在外部被修改

先比较磁盘版本与当前未保存内容，不要在不确认差异时覆盖。必要时另存一份副本再处理。
