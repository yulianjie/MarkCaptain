# 常见问题与排查

[首页](https://github.com/yulianjie/MarkCaptain/wiki/Home) · [使用指南](https://github.com/yulianjie/MarkCaptain/wiki/%E4%BD%BF%E7%94%A8%E6%8C%87%E5%8D%97) · [功能总览](https://github.com/yulianjie/MarkCaptain/wiki/%E5%8A%9F%E8%83%BD%E6%80%BB%E8%A7%88)

## 找不到文档里提到的入口

先在“帮助/关于”核对版本，再用命令面板搜索动作名称。部分功能要求打开项目、文档或切换所见即所得模式。本 Wiki 对应 0.8.7，较早版本可能没有部分入口。

## Windows 无法启动或窗口异常

记录系统报错，确认使用适合架构的软件包与可用的 WebView2 Runtime。使用多显示器、缩放或断开显示器后，先检查窗口是否移到其他屏幕；需要固定尺寸时查看窗口尺寸记忆设置。反馈时提供系统、版本和复现步骤。

不要先删除整个应用数据目录，它可能包含本地历史、草稿和自定义技能。需要清理前先备份项目及所需应用数据。

## 文档已保存，为什么仍显示等待同步

“已保存”只代表写入本地。云端连接、网络、认证和冲突单独决定同步状态。到云存储设置查看最近同步结果；离线时本地编辑仍可继续，恢复网络后明确执行同步并检查冲突。

## 为什么未命名文档没有自动保存或本地历史

先手动保存一次并选择路径。自动保存不会替未命名标签自动选择文件名，本地历史也需要稳定路径；首次保存前由崩溃草稿保护。自动保存默认关闭，可在设置中启用。

## 文件被外部程序改动，应该选哪个版本

先保留当前未保存内容，再比较磁盘版本。遇到冲突时自动保存会暂停，应按提示解决后手动保存。需要回溯时尝试本地历史，但历史按定时检查记录，两次检查之间的改动不一定都有快照。

文件位于网络共享目录时，外部修改可能无法被及时发现；切换到文档前可重新打开以获取最新内容。

## 图片换一台设备就不显示

检查 Markdown 中是否是原设备绝对路径，图片是否随文档复制，大小写和相对层级是否一致。建议项目内相对图片目录。HTML 使用资源目录导出时，也必须连同资源目录一起交付。

图片上传失败应另查上传器、可执行路径、目标服务和凭据；GitHub 上传 Token 是会话内设置。它与 Agent 图片问答、云存储同步不是同一个通道。

## 链接点不开或跳错笔记

普通单击用于编辑链接，不会跳转；使用 `Ctrl/Cmd+点击` 或链接浮层的跳转按钮。检查相对路径、URL 编码、目标是否存在和标题写法；项目内同名笔记用完整相对路径消除歧义。PDF 等非 Markdown 文件不会被伪装为笔记创建。

- **目标文件不存在**：编辑器内会显示错误并保留当前文档，不会打开浏览器。
- **`[章节](#标题)` 不滚动**：0.8.7 起会在当前文件内滚动到对应标题（支持中文标题）；旧版本请升级。
- **单击链接打开了浏览器或 `tauri.localhost` 页面**：0.8.6 修复了 Ctrl/Cmd+点击跳转被当作网页的问题，0.8.7 修复了普通单击的同类问题；请升级到 0.8.7。
- **单独打开的文件无法跳转到相对链接**：0.8.6 起无需打开项目也能跳转。
- **链接浮层残留、遮挡正文**：0.8.7 已修复。

双链和补全依赖项目索引，应查看索引是否完成或受限。

## 为什么搜索、双链和任务结果不同

全文搜索、笔记索引、结构化查询、Agent 项目检索分别有范围和规则。代码示例不会作为真实任务，符号链接和生成目录也可能被某些功能排除。检查索引完整性和数量/大小限制；不完整不代表剩余范围没有匹配。

结构化搜索中 AND 优先于 OR，当前不支持括号；带空格的值使用双引号。

## Agent 连接失败或不支持修改

检查基础地址、模型 ID、认证模式、密钥与自定义头，以及服务是否支持流式 Chat Completions 和工具调用。更换地址后旧地址的密钥不会自动提供给新服务；无认证服务可选择“无认证本地服务”。

Linux 凭据库失败时确认 Secret Service 可用且已解锁。连接测试通过表示地址、认证、流式输出和工具定义可用，但不代表模型支持图片或能正确完成工具调用。不要把 API Key、认证头或含秘密的完整请求贴到 Issue。

## Agent 没读文档或读不到项目资料

检查本轮是否附加当前文档/选区、参考资料是否被移除，以及项目搜索是否已授权。打开项目本身不授予模型读取权限。初始请求通常只有元数据，正文由模型按需调用工具；查看实际读取记录。

恢复历史会清空附加范围和运行时授权，需要重新配置本轮上下文。只读检查与多文档修订也不会自动继承普通聊天的所有资料权限。

## 修改建议过期、冲突或无法撤回

继续编辑、外部变化、保存和标签身份变化都可能使旧快照失效。不要为了应用旧建议强行覆盖；重新比较或发起请求，检查新卡的目标范围。

多文档修订按文件校验，应用后需手动保存。旧建议在保存后也可能过期。跨文件没有全局撤销，切换到对应文档使用正常撤销，或按卡片允许的方式撤回。

## 重启后历史卡片不能应用，图片也不见了

历史审阅卡默认只读，不自动重放修改。需要继续时显式重新关联并校验待审项，通过文件选择器选择当前 Markdown；只有可验证项产生新卡。图片没有持久化，需重新附加。

多文档任务的原文副本和审阅仅保留当前会话，不属于可跨重启恢复的普通 Agent 历史。

## 联网研究失败

确认本轮启用研究、查询词已逐条批准，或直接 URL 属于公开 HTTP/HTTPS 常用端口。私网、localhost、登录网页及非常用端口不属于范围。

搜索使用 Bing RSS，可能不可用；可自行添加公开文章 URL。请求不使用系统代理，系统代理下能打开网页不保证研究可访问。启用 Cloudflare 公共 DNS 时若解析失败，不会静默改用系统解析，可按错误检查网络或明确调整该选项。

## 导出 PDF 或办公文档失败

先区分系统打印和 Pandoc 转换：打印不依赖 Pandoc，打印对话框打开后仍需在系统中完成保存才会得到 PDF；Pandoc PDF 需 Pandoc 与 PDF 引擎，DOCX/ODT/EPUB 需 Pandoc。查看窗口中的依赖检查和转换错误。

项目批量/成册 PDF 走 Pandoc，不会回退为逐篇系统打印。预览过期时先刷新，不要用旧预览判断新输出。

## 导出后图表、字体或表格与编辑器不同

导出主题独立，办公文档和电子书还有各自阅读器规则。需要外部服务/资源的图表可能保留源码；远程图片不自动下载。宽表可选横向纸张、较小字号或拆分列，最终在目标阅读器检查。

远程图片保留外部 URL 的 HTML 需要网络；资源目录模式需要一起复制资源。预览不打开外部链接是预期行为，成品仍保留相应链接。

## 批量导出有失败项，能否重试

查看逐项结果。“校验版本并重试失败项”保留成功项；来源改变、新警告或之前没有冻结成功的来源可能要求重新冻结审阅。默认不覆盖已有输出，确需替换时明确启用覆盖并重新冻结。

合并成册缺一章会阻止输出，避免生成不完整手册。取消前已成功的文件会保留，不等于整个任务回滚。

## Git 分叉或 WebDAV 冲突

先保留工作副本。Git 常规同步只做安全范围内的 fetch、快进和非 force push；分叉需明确准备审阅合并或用 Git 工具处理，不会自动 reset/提交/强推。WebDAV 缺少可靠版本或双方变化时不能安全静默覆盖。参见[同步与数据安全](https://github.com/yulianjie/MarkCaptain/wiki/%E5%90%8C%E6%AD%A5%E4%B8%8E%E6%95%B0%E6%8D%AE%E5%AE%89%E5%85%A8)。

## 更新怎么工作

通用设置的自动检查默认开启，主编辑器启动后约 10 秒检查，运行期间每 4 小时检查。自动检查只有发现更新才弹窗，网络失败保持安静；“帮助 → 检查更新”会显示错误并允许重试。

只有点击下载与安装才获取更新包，签名或安装失败不会显示为安装成功。安装前关闭其他编辑器窗口；应用保存打开文档、刷新 Agent 数据并记录会话。另存为取消或保存失败会暂停安装，完成后按平台提示重启。

更新签名与 Windows/macOS 系统代码签名是不同机制。无可用清单、签名或合法更新配置时，不能把失败检查当成“已经最新”。必要时从[Releases](https://github.com/yulianjie/MarkCaptain/releases)手动安装适用版本。

## 如何反馈问题

在[项目 Issues](https://github.com/yulianjie/MarkCaptain/issues)先搜索，再提供：

1. 应用版本、系统与架构、安装包类型。
2. 最短复现步骤、预期结果和实际结果。
3. 发生在源码还是所见即所得模式，是否分屏、开启自动保存或使用项目。
4. 必要的脱敏示例、截图和错误信息；导出问题注明格式、主题及依赖。

用虚构内容重现，移除私人正文、密钥、Token、认证头和临时 MCP 凭据。
