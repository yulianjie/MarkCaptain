# 导出与成册

[首页](https://github.com/yulianjie/MarkCaptain/wiki/Home) · [编辑与工作区](https://github.com/yulianjie/MarkCaptain/wiki/%E7%BC%96%E8%BE%91%E4%B8%8E%E5%B7%A5%E4%BD%9C%E5%8C%BA) · [常见问题](https://github.com/yulianjie/MarkCaptain/wiki/%E5%B8%B8%E8%A7%81%E9%97%AE%E9%A2%98)

导出围绕冻结的文档快照、独立预览、主题和资源预检工作。未保存正文可以进入导出，但导出不会自动保存源文件。单篇、逐篇批量输出和合并成册共用相关排版与资源规则。

## 格式与依赖

| 输出方式 | 依赖 | 得到什么与如何确认 |
| --- | --- | --- |
| HTML | 无需 Pandoc | 带样式 HTML，可选择内嵌图片或独立资源目录 |
| 系统打印 / 保存 PDF | 系统打印能力，无需 Pandoc | 打开系统对话框；完成打印或“保存为 PDF”后才有成品 |
| Pandoc PDF | Pandoc + 可用 PDF 引擎 | 实际写出 PDF；当前探测 XeLaTeX、Typst、WeasyPrint |
| DOCX | Pandoc | 办公文档，在目标阅读器核对排版 |
| ODT | Pandoc | OpenDocument 文档，在目标阅读器核对排版 |
| EPUB | Pandoc | 电子书，最终分页和显示受阅读器影响 |

应用不打包 Pandoc。依赖预检失败时先解决本机环境；转换失败不能算导出成功。项目批量/成册的 PDF 使用 Pandoc，不为每篇打开系统打印对话框。

## 单篇导出步骤

1. 通过文件菜单中的 HTML、DOCX、ODT、EPUB 或打印入口打开统一导出窗口。
2. 选择格式、主题和排版。可以使用个人默认、项目预设，再做本次调整。
3. 生成预览，冻结当前文档缓冲区、格式、项目范围和排版选项。
4. 查看资源、转换依赖、链接和布局警告。
5. 文档或设置变化时刷新预览；过期快照不能继续混用新设置输出。
6. 选择输出位置并导出，或明确打开系统打印。
7. 在实际浏览器、PDF/办公文档/电子书阅读器中检查成品。

取消可以停止后续尚未开始的步骤，关闭窗口也会取消未完成工作。选择保存路径、预检和写出期间的取消都不等于已经删除旧成品。

## 主题与排版

提供三套浅色主题：简洁阅读、技术文档、正式报告。导出主题独立于编辑主题，可配置纸张、方向、边距、字体别名、字号、行距、目录和编号，具体按格式支持情况生效。

HTML/打印使用禁止脚本的独立 iframe，输出不含编辑器工具栏、光标和 Agent 审阅标记。公式字体可内嵌，支持的图表转成静态输出。

Pandoc 使用同一份处理资源后的 HTML。DOCX/ODT 通过参考文档映射字体、颜色和页面参数，未映射的行距设置会禁用；EPUB 使用 CSS。预览对这些转换格式属于内容近似，不能保证逐像素一致。

超过 8 列的表格会提示布局风险。可尝试横向纸张、较小字号或拆分表格，并检查最终文件；自动折行不保证宽表在纵向纸张上可读。

## 图片、公式、图表与链接

- 本地图片按源文档位置及授权项目范围解析，单资源最多 16 MiB。已保存路径仍需处于本进程正常读取/保存的授权范围。
- HTML 可使用图片内嵌或资源目录。资源目录按任务命名，交付时需连同 HTML 一起复制。
- 远程图片不会在预览或 Pandoc 转换中自动下载。HTML 保留外部引用时依赖网络，不能称为完全离线成品。
- 当前“下载远程资源”选项没有实际下载能力，启用会阻止导出并说明原因。
- PlantUML、需要外部资源或自定义配置的 Mermaid 等可能保留可读源码并提示；导出不会借预览调用远程渲染服务。
- Vega 只允许内联数据，禁止外部数据/图片加载；普通 Mermaid、公式及可安全处理的图表按共享流程渲染。
- 单文档标题和脚注按实际锚点跳转，普通 Wiki 链接转为链接；未打包的跨文档目标会提示。

预览里的同文档锚点在正文内滚动，外部网站和其他文件不会从预览中打开；实际输出仍保留相应链接。单篇导出不会自动收集整个项目作为配套页面。

## 个人默认与项目预设

有效配置顺序为：内置默认 → 个人默认 → 项目预设 → 本次调整。只有明确保存到项目时才写入 `.markcaptain/export.json`，保存预设不会开始导出。

项目配置版本为 1，使用相对路径，默认输出目录为 `exports`。保存前比较配置指纹；外部修改后需重新加载，避免覆盖。未知字段保留，无效或未知版本不会被默认值静默覆盖。

所有预设声明的输出目录会从笔记枚举、Agent 项目检索和项目导出候选中排除，避免把生成物重新当作输入。没有项目时使用个人默认和保存对话框批准的位置。输出不能覆盖源文档。

## 批量导出多个文档

打开项目，在单篇导出窗口点击“导出项目…”，选择“分别导出文档”。

1. 筛选并勾选候选文档，最多 64 篇；可把未命名标签加入本次任务。
2. 选择主题/预设、多个格式、文件名规则和输出设置。
3. 点击“冻结快照并审阅”，检查来源版本、实际文件名、预览和警告。
4. 点击“导出已审阅快照”，查看每篇、每种格式的独立结果。

打开且未保存的有路径文档使用缓冲区，其余文件从磁盘读取；未命名文档使用所选标签正文。写出只使用冻结结果，后续编辑不会偷偷混入成品。

批量预览显示当前任务的首份成品，结果表列出全部输出。某篇读取、渲染或某种格式失败不会把其他已成功文件标成失败。

## 合并成册

选择“合并成册”，显式设置章节清单。选择顺序是默认顺序，可上移、下移、移除，修改章名和标题层级；目录遍历顺序不会直接作为章节顺序。

每章先按自身来源目录处理图片，再组合正文。成册处理章节命名空间、重复标题、脚注、图表/SVG 引用和跨章链接，避免不同目录同名图片混用。目录按实际标题生成，章节正文标题置于章节标题之下；超出六级标题时会提示。

只有纳入清单且可明确解析的目标才能映射到对应章节；缺失或有歧义的目标会提示。任何选中章节不可用时会阻止成册，不静默发布缺章书籍。成册预览展示完整手册。

批量输出中的已纳入笔记链接会改为对应格式成品文件名；外部文件锚点在 PDF/办公阅读器中的可用性由阅读器决定。

## 覆盖、重试与取消

默认不覆盖已有输出。同名输出存在时保留旧字节并报告该项失败；需要替换时明确勾选“替换已有输出文件”，重新冻结并审阅。

批量名称支持 `{name}`、`{profile}`、`{date}`，附加按来源路径身份生成的稳定后缀。非法字符、Windows 保留名和重名会被处理，开始前显示实际文件名。成册使用指定书名和格式扩展名。

“校验版本并重试失败项”会重新核对整个来源清单，包括脏缓冲区和未命名标签。版本改变则重新准备；成功项保留，不重复写出。新警告或恢复渲染的章节需要再次审阅；没有冻结成功的来源必须重新冻结。

取消停止尚未发起项并取消正在执行的后端任务，之前已提交的成品保留。关闭窗口不在后台自动恢复任务。

## 保存项目方案

方案保存在 `.markcaptain/export.json` 的可选 `projectExport` 字段，包含章节相对路径、顺序、标题、格式及设置。不会保存正文、未命名标签身份或运行权限，也不会自动开始导出。

修改输出目录后，应先保存方案，使其成为项目配置中的输出目录。未命名文档可用于当前任务，但无法保存为持久章节路径。建议通过界面保存，避免把示意配置当作完整预设手写。

## 当前限额

| 范围 | 限额 |
| --- | --- |
| 项目候选 | 5,000；超限明确失败，不返回貌似完整的截断清单 |
| 选择文档 | 64 篇 |
| 单篇冻结正文 | 2,000,000 UTF-8 字节 |
| 全任务冻结正文 | 4 MiB，含未命名文档 |
| 累计准备 HTML | 48 MiB |
| 导出配置 | 格式化 JSON 最多 256 KiB |

详细流程见[单篇导出](https://github.com/yulianjie/MarkCaptain/blob/master/docs/M1_WORKFLOWS.md)与[项目导出](https://github.com/yulianjie/MarkCaptain/blob/master/docs/M3_WORKFLOWS.md)。
