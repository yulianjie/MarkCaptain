## 文件、项目与标签

可以独立打开一个 Markdown 文件，也可以打开文件夹作为项目。单文件编辑不要求创建项目配置；项目提供目录树、项目搜索、笔记索引和项目方案。

“文件”菜单支持新建、打开、打开文件夹、保存、另存为、全部保存及关闭等操作。最近使用入口用于重新打开文件。多标签共享窗口，另可通过“新建窗口”（`Ctrl/Cmd+Shift+N`）打开独立窗口。

文件树提供文件和目录管理。重命名或移动项目笔记可能涉及其他笔记的引用，优先使用应用内操作并检查引用预览，参见[引用维护](https://github.com/yulianjie/MarkCaptain/wiki/%E7%AC%94%E8%AE%B0%E4%B8%8E%E7%9F%A5%E8%AF%86%E7%AE%A1%E7%90%86#%E9%87%8D%E5%91%BD%E5%90%8D%E7%A7%BB%E5%8A%A8%E4%B8%8E%E5%BC%95%E7%94%A8%E7%BB%B4%E6%8A%A4)。

标签未保存状态与磁盘文件不同。关闭有修改的标签或窗口时，应按提示保存、取消或放弃。不要把关闭标签当作已保存操作。

## 所见即所得与源码

默认 Muya 编辑器直接显示 Markdown 的排版。源码模式提供原始文本编辑，适合精确调整 YAML、复杂链接、图表代码或排查格式。通过“视图 → 源码模式”切换，默认快捷键是 `Ctrl/Cmd+Alt+S`。

两种模式围绕同一份文档缓冲区工作。部分段落/格式菜单只适用于所见即所得模式，在源码模式中使用 Markdown 语法或源码编辑操作。

| 内容 | 常用写法或操作 | 注意事项 |
| --- | --- | --- |
| 标题与引用 | `# 一级标题`、`## 二级标题`、`> 引用` | 标题形成大纲，便于跳转 |
| 行内格式 | `**粗体**`、`*斜体*`、`~~删除线~~`、反引号代码 | 可用格式菜单或工具栏 |
| 列表与任务 | `- 条目`、`1. 条目`、`- [ ] 待办` | 任务聚合见笔记面板 |
| 表格 | Markdown 表格或插入表格对话框 | 宽表导出需检查纸张和字号 |
| 代码块 | 围栏代码块加语言标识，如 `javascript` | 可配置代码字体与行号 |
| 链接与图片 | `[说明](目标)`、`![说明](assets/image.png)` | 图片策略会影响文件放置和上传 |
| 公式 | 行内/块级数学公式 | 使用 KaTeX 排版，复杂语法需检查支持情况 |
| 脚注、上下标、HTML | 对应 Markdown 扩展或 HTML | 部分扩展默认关闭，需在设置中启用 |
| Frontmatter | 文首 YAML 等元数据块 | 笔记属性编辑针对可支持的 YAML 值 |
| 图表 | Mermaid、Flowchart、Sequence、PlantUML、Vega-Lite 围栏 | 各格式的渲染及外部资源策略不同 |

例如可以在源码模式粘贴，再切回查看：

````markdown
# 发布计划

- [ ] 校对说明
- [x] 确认目录

| 模块 | 状态 |
| --- | --- |
| 文档 | 进行中 |

```mermaid
flowchart LR
  A[起草] --> B[审阅] --> C[导出]
```
````

编辑器支持某种图表不意味着导出使用同样的渲染方式，例如 PlantUML 在导出时保留源码，见[导出与成册](https://github.com/yulianjie/MarkCaptain/wiki/%E5%AF%BC%E5%87%BA%E4%B8%8E%E6%88%90%E5%86%8C)。

## 工具栏、右键与复制粘贴

常见格式可从菜单、工具栏、右键菜单或命令面板触发。支持复制为 Markdown、复制为 HTML，以及粘贴为纯文本。需要保留原始语法时先检查复制方式，避免将富文本样式意外带入其他程序。

图片可通过文件选择、粘贴或拖放插入。图片设置分为引用原路径、复制到文件夹和上传；默认引用路径。复制时可使用文档相对图片目录（默认名称 `assets`）或指定目录。上传器包括 GitHub、PicGo 和自定义脚本，外部程序和服务需要自行配置。GitHub 图片上传 Token 仅在会话中保存，不能套用 Agent 密钥的持久化规则。

跨设备文档建议使用项目内相对路径，并把图片目录一起复制或同步。未命名文档还没有所在目录，建议先保存再插入图片。

## 查找、替换与项目搜索

- 当前文档：“编辑 → 查找/替换”。
- 项目全文/正则搜索：左侧搜索面板；偏好设置提供排除规则、文件大小、隐藏文件、忽略规则和符号链接选项。
- 按名称、路径和别名找笔记：快速打开。
- 按标签、属性与任务组合筛选：结构化搜索，见[笔记与知识管理](https://github.com/yulianjie/MarkCaptain/wiki/%E7%AC%94%E8%AE%B0%E4%B8%8E%E7%9F%A5%E8%AF%86%E7%AE%A1%E7%90%86)。

各入口的默认快捷键见[快捷键与偏好设置](https://github.com/yulianjie/MarkCaptain/wiki/%E5%BF%AB%E6%8D%B7%E9%94%AE%E4%B8%8E%E5%81%8F%E5%A5%BD%E8%AE%BE%E7%BD%AE)。

这些功能与 Agent 的项目检索分别管理。搜索面板的文件规则不会给模型授予访问权限；笔记索引也有更保守的排除和大小限制。

## 大纲与右侧检查器

大纲列出当前文档的标题，点击可跳转。右侧检查器可切换大纲、双链和 AI 助手；收起后从右侧图标重新打开。窄窗口中默认收起，手动打开可呈现浮层。

双链支持按来源分组、筛选、展开上下文、固定目标、在当前或另一分屏定位，并返回原文档与光标。固定双链后可与 Agent 上下并用，不必反复切换面板。

## 分屏与命名布局

通过命令面板选择“左右分屏”“上下分屏”“关闭区域”。最多四个区域，整个布局按左右或上下方向排列；每区可通过下拉框选择文档。点击区域决定当前活动区域，Agent、模板插入等操作跟随活动区域。

拖动分隔线调整大小，也可聚焦分隔线后用方向键调整。关闭区域不会关闭文档标签或丢弃未保存内容。

同一文档在多个区域中共享正文、保存状态与撤销序列，各区域有自己的光标、选区和显示模式。一个区域中的编辑会在另一区域反映；它们不是两份独立副本。

“保存的布局”可保存、恢复和删除命名布局。保存内容包括区域方向、比例、活动区域、文档路径、模式和光标/选区；不包含正文或完整撤销历史。命名布局按项目区分，存于 WebView 本地存储。未命名文档没有可持久化路径，恢复布局不能代替草稿恢复。

## 保存、编码与外部修改

支持自动猜测文件编码，并可在设置中选择默认编码、LF/CRLF 与末尾换行策略。底部状态栏显示编码、BOM、换行符、保存状态、编辑模式及字数等信息；它是状态展示，相关配置在设置或相应入口中调整。

自动保存默认关闭，在“偏好设置 → 通用”中开启。它只对已有路径的文档工作；未命名标签不会因定时器突然弹出另存为对话框。

文件监视发现外部变化时，会按当前是否有未保存修改提示处理。遇到冲突应先保留副本，再比较磁盘和缓冲区。存在冲突时自动保存会暂停，需按提示完成处理并手动保存。文件监视使用系统原生通知；网络共享目录上的外部修改可能无法及时发现，切换回文档前可重新打开以确认最新内容。

应用提供会话恢复和崩溃草稿保护。启动行为可选择空白页、上次状态或指定文件夹。独立本地历史另外保存已命名文档的版本，使用方法见[同步与数据安全](https://github.com/yulianjie/MarkCaptain/wiki/%E5%90%8C%E6%AD%A5%E4%B8%8E%E6%95%B0%E6%8D%AE%E5%AE%89%E5%85%A8)。

## 专注与窗口

视图菜单提供专注模式、打字机模式以及侧栏、标签栏、工具栏和状态栏显隐。可缩放界面、全屏、置顶，或调整编辑区字体、行宽、行距与文本方向。

Windows/Linux 使用应用自带的标题栏与菜单（可用 `Alt+F` 等助记键打开菜单），macOS 保留系统标题栏和应用菜单。窗口尺寸记忆默认关闭，可按需开启；主题、窗口效果和系统行为依平台而异。编辑主题与导出主题分别设置，改变编辑器颜色不会自动改变成品样式。
